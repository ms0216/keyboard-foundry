# 外部から取り込んだフットプリント

## keyswitch.pretty

出典: [kiswitch/kiswitch](https://github.com/kiswitch/kiswitch)
（MIT ／ CC-BY-SA 4.0 のデュアルライセンス）

KiCad 標準ライブラリには **3.00u** と **ホットスワップソケット**が無いため取り込んだ。
キー幅 → フットプリントの対応は foundry/mech.py の `Switch.fp`。**無い幅は足す**
（近い幅で代用するとシルクのキャップ外形が嘘になる。上流から取り、パッドと穴が 1u と
一致することを確かめる。2.75u は 2.25u とパッド・穴が完全一致だった）。

| ファイル | 用途 |
|---|---|
| `SW_Hotswap_Kailh_MX_1.00u` | 通常キー |
| `SW_Hotswap_Kailh_MX_1.50u` | Tab / ◇ ×2 / Delete |
| `SW_Hotswap_Kailh_MX_1.75u` | Ctrl / 右Shift |
| `SW_Hotswap_Kailh_MX_2.25u` | Enter / 左Shift |
| `SW_Hotswap_Kailh_MX_2.75u` | L-Space / R-Space（HHKB） |
| `SW_Hotswap_Kailh_MX_3.00u` | 3u のキー |
| `Stabilizer_Cherry_MX_2.00u` | 2.25u キー用（間隔 ±11.938mm） |
| `Stabilizer_Cherry_MX_3.00u` | 3.00u キー用（間隔 ±19.05mm） |

## 寸法を検証した記録

**取り込む前に、規格値と照合した。** フットプリントを間違えると基板が
まるごと無駄になるので、他人のライブラリでも鵜呑みにしない。

`SW_Hotswap_Kailh_MX_1.00u` のパッド（キー中心からの相対位置）:

| パッド | 位置 | 規格値 | 判定 |
|---|---|---|---|
| スイッチピン穴 1 | (−3.810, −2.540) φ3.05 | MX 標準 (−3.81, 2.54) | ✅ |
| スイッチピン穴 2 | (2.540, −5.080) φ3.05 | MX 標準 (2.54, 5.08) | ✅ |
| 中央ポスト | (0, 0) φ4 | MX 標準 φ4 | ✅ |
| 位置決めポスト ×2 | (±5.080, 0) φ1.75 | MX 標準 φ1.75 | ✅ |
| ソケット端子 1 | (−7.085, −2.540) **B.Cu** | Kailh CPG151101S11 | ✅ |
| ソケット端子 2 | (5.842, −5.080) **B.Cu** | 同上 | ✅ |

Y の符号が反転しているのは KiCad が Y 下向きだから。

**ソケットが裏面（B.Cu）にある**ことも確認した。ケース設計の前提
（基板下へ出る。データシート PG151101S11 で 1.80mm・ボス込み 3.05mm）と一致する。

スタビライザーの間隔（±11.938 / ±19.05mm）も Cherry の規格
（0.47 / 0.75 インチ）と一致した。**この値はプレートと共有する必要があるので
`foundry/mech.py` に置いてある。** 基板側とプレート側で別々に持つと
食い違う（以前ネジボスの位置で実際にやらかした）。

## xiao.pretty / xiao.3dshapes

Seeed XIAO nRF52840 のフットプリントと公式 STEP（HHKB で作り、14 穴をメーカー公式
ライブラリと鏡像・回転 8 通りで照合して 0.000mm 一致）。出所は xiao.3dshapes/README.md。
