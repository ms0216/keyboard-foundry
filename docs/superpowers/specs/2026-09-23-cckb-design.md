# CCKB（Completely Compact KeyBoard）設計書

2026-09-23 利用者と合意。**HHKB 英語配列に準拠し、出張先や会議室へ持ち運ぶための、薄く軽い一体型キーボード。**
HHKB（Professional HYBRID Type-S・294×120×40mm・540g）は机に据えて使い、CCKB は鞄に入れて持ち出す。
使うのは出張・会議のときだけ（毎日一日中ではない）。印刷は Bambu Lab A1 mini（D12）。

完了とは**発注できる状態**（下の §9）。発注・印刷・購入は利用者が判断する。

## 4. 回路

```
CR1632 → 電源スイッチ → [分圧 1MΩ+1MΩ → XIAO の ADC] → ショットキー D_PWR（既定 BAT46W）→ XIAO 3V3
                                                             （BAT 端子には繋がない）
行 5 本 ── XIAO 直結（入力・プルダウン）
列 15 本 ── 74LVC595 ×2（SPI: SCK=D8・MOSI=D10・CS=D7。D9 は MISO に確保）
キーごとに BAT46W（col2row）
```

- GPIO は 11 本中 9 本（行 5・SPI 3・ADC 1）
- 行列は 5×15。キーの割り当ては `foundry/matrix.py`（physical）を初期値にする
- 電源スイッチは必須（鞄の中でキーが押されて起きるのを止める）
- ショットキーは USB 給電中に一次電池を充電しないため（Energizer: 逆充電は 1µA まで）。
  B5819W は低い逆電圧の逆漏れに保証が無く、USB を挿したままスイッチ ON だと電池へ数 µA が向かいうる（監査 A-1）。
  ~~替えられる品が無い~~（1 回目の比べ方は誤り）→ **既定を BAT46W に替えた**: 25℃ では逆漏れの保証値 0.3µA が分圧の吸う
  0.93µA より小さく電池へ入らない（決定記録 2026-09-24-audit-fixes §S2・open-gaps O12）。高温では保証が無いので
  「**USB を挿す前に電源スイッチを OFF**」は残す
- 直付けなのでソケットの「2V 以上」の制約は無い。打ち止めはマイコンの下限（レール 1.8V）と起動の実測で決める

## 5. 機構

> **2026-09-24 に境界を決めた（projects/cckb/docs/decisions/2026-09-24-interface.md）。**
> 下の「上枠」は**トレイ（底＋外壁）＋角のふた**に変えた（上枠の前後の辺を基板に留める場所が無い。
> 2026-09-24 に利用者がこのままと決めた・open-gaps O8）。基板は 1.6mm（O3）、取付 10（O4）、電源スイッチ SS-12D00G3（表・右の角・ふたの穴から爪で操作。
> 2026-09-24 に MK-12C02-G025 から置き換え・decisions/2026-09-24-power-switch.md）。
> 高さ・外形の数値は決定記録の §2-5 と spec.py が正本。

### 積み重ね（下から）

1. 底板（PLA）。四隅に面一の滑り止め
2. 基板（**1.2 か 1.6mm。§8 の検査で決める**。全体の背骨なので 1.6mm が有力）。裏の部品とスイッチの足で下に約 1.5mm
3. プレート（PLA 1.2mm・2 分割）。基板上面からプレート上面まで 2.2mm（Choc 規格）
4. スイッチ・キーキャップ

**プレート・スイッチ・基板ははんだで一体になる。**これを上枠と底板で挟む。

### 角（この設計の中心）

| | 左の角 | 右の角 |
|---|---|---|
| 大きさ（最下段の空き） | 1.5u×1u ＝ 28.6×19.05mm | 2.5u×1u ＝ 47.6×19.05mm |
| 置くもの（基板の表側） | XIAO（21×17.8mm）。USB-C は左側面へ | CR1632 とホルダ |
| 上面 | 上枠と同じ平らな面 | 角の上面をまるごと 1 枚のふた（ネジ 1 本か、落ちない爪） |

- 電源スイッチは側面（位置は作図で決める）
- 上枠は角を覆うので、プレートと基板の一体物は**下から入れる**（上枠 → 一体物 → 底板の順にネジで留める）
- XIAO のアンテナは USB と反対の端（内側を向く）。アンテナ直下の銅を抜く（docs/knowledge/rf-antenna.md）

## 6. ファーム（ZMK）

- シールド `cckb`・ボード `xiao_ble//zmk`・CI で .uf2 を作る
- キーマップ: HHKB の既定（ベース面・Fn 面）。スペース 3 つとも `&kp SPACE`。`&bootloader`・`&bt BT_CLR` を置く
- 電池残量: `firmware/` の残量計（foundry,battery-alkaline）をそのまま使う。中身は電圧の窓を % にする線形の写像で化学に依らないので、窓を CR1632 の値にするだけ
- 打ち止め: §10a の起動試験の結果から決める（`low_battery_off`）
- 設定は HHKB の定石（docs/knowledge/zmk-and-xiao.md）: スリープ 30 分・Apple §58.6 適合の接続間隔など

## 7. 核（foundry/）の改修

いまの核は MX 専用（mech.py の開口 14.0・SWITCH_FP・Cherry スタビ・pcb.py の Value "CPG151101S11-2"・DIODE_OFFSET）。

- spec.py に **`SWITCH = "mx_hotswap" | "choc_v1"`** を足し、スイッチの種類ごとの規格値（開口・フットプリント・スタビの形と間隔・ダイオード位置・部品番号）を mech.py の表にまとめる
- 既定値で埋めない（`REQUIRED` に入れる）。HHKB の fixture spec には `"mx_hotswap"` を書く
- Choc の直付けフットプリントは kiswitch（perigoso）の上流から取り、**端子の位置と向きを Kailh の図面 CPG135001D01 と突き合わせる検査**（kiswitch と Keebio は KiCad 座標で (0, −5.9)・(5, −3.8)、中心穴 φ3.45、ボス φ1.9 を ±5.5）を置く
- **HHKB の再現検査（tests/test_regression_hhkb.py）を通す**
- 生成器は寸法を持たない（寸法は spec.py と mech.py）

## 12. 配線の方針

- キーの行列は**道具が決まった形で引く**（行＝裏面の横、列＝表面の縦。スイッチ → ダイオードの L 字）。道具は写すだけにし、配線を加工する判定を書かない
- XIAO・595・電源まわりは Freerouting 2.3.0（手元に jar あり。**Java（OpenJDK）を Homebrew で入れる**）
- 2 層・両面 GND ベタ。塗った後の面積で健全性を見る。アンテナ直下の禁止域は塗られた後のベタで確かめる
- DRC 0 は配線が良いことを意味しない。層ごとの長さ・ビア数・GND の島・遠回りの比を数字で出し、絵で見る
