# 筐体と 3D プリント

foundry が自動で作るのは**プレートまで**（`tools/kb <機種> plate`）。ケースは機種ごとの
意匠そのものなので、HHKB の `tools/{gen_case,gen_assembly,envelopes,interface}.py` を
参照実装として読む（2 台目を作るときに共通部分を foundry へ抜き出す）。

## プリンタ

| | K1 Max | A1 mini |
|---|---|---|
| ベッド | 300³ | 180³（**CLI の自動配置は実効 168.4mm 角**。GUI で端に置けば 177.6 を実機で完走） |
| 前提 | PLA・0.4 ノズル・0.2 層・耐熱約 60℃・オーバーハング 45° | 同左・印刷時間は K1 Max の 2.4〜4.3 倍 |

- **スライサーに通したものだけを「刷れる」と言う**（`tools/kb <機種> slice`）。
  生成器より古い STL は刷れると言わない（廃止した部品の STL を 8 か月「刷れます」と言い続けた）
- 印刷を渡すときは**回した検査／回していない検査**を書き、刷るかの判断を返す
- 試し刷りは変わった帯だけを切り出す。検査用の出力は `_` 始まりにして本番と混ぜない
- 入らない部品の打ち手: 大きいプリンタ / 分割して接合 / 外注 / 余白を詰める（実機に無い分割面だけ）

## スライサーを CLI で回すとき（cckb-click で分かったこと・2026-10-03）

- **CLI は設定の継承（inherits）をたどらない。**Bambu の設定をそのまま渡すと OrcaSlicer の既定値（外周 60 mm/s・ノズル 200℃・
  ベッド 35℃）で切られる。親をたどって 1 枚にしてから渡し、**G-code の末尾の設定の欄と突き合わせる**
  （projects/cckb-click/tools/slice_precise.py。foundry/slice_check.py はまだ直していない）
- CLI の自動配置は物を**回すことがある**（180°）。向きで決まる設定（継ぎ目を奥に）を見るときは、自分で真ん中へ動かして自動配置を切る
- Bambu Studio の CLI も同じ引数で動く。利用者が刷るスライサーで確かめる
- **継ぎ目（外周の線の始まり）は、角の丸い形ではスライサーの設定だけでは置き場所を選べない**（丸みの始まりに出る）。
  滑る面にこぶを出したくない形には、辺の真ん中に小さな溝（幅 2.0・深さ 0.5）を掘り、継ぎ目を「そろえる」にすると溝の入隅に出る。
  1.2 × 0.3 の溝は 0.4 ノズルでは選ばれなかった
- 精度が要る小物: 層 0.1・外周の順は内→外→内（3 本以上）・ブリム無し・1 層目の太りは形の面取りで逃がす・測る所（外寸 10 と内寸 10）を一緒に刷る

## 寸法の作法

- **肉厚はノズル径の倍数**（1.2 / 2.4）。**0.4 未満は「無い」と同じ。**.blend や STL は厚さ 0 に
  近い膜も面として描くので、**見える＝刷れるではない**。「ある」と言う前に、部品を名指しして
  断面を描き厚みを測る（0.2 の膜を壁と誤認し上シェルを無駄に刷らせた）
- 嵌合の隙間: 印刷どうし 0.2（両側合計）、プレートの切り欠き 0.1（片側）。**未実測なら先に公差の
  クーポン**（丸穴と角穴の両方。角は隅に材料が寄ってきつくなる）
- **傾けて載せる板は、平面図の奥行が cos(傾き) 倍に縮む**（＋板厚×sin）。平らな寸法と平面図の
  寸法を別の名前で持つ（取り違えを 3 度踏んだ）
- MX: プレート厚 1.5・プレート上面からソケット下端まで 9.8mm（Topre より 5mm 以上厚い）
- スタビの開口は swillkb のパスを多角形オフセットで広げる。**スイッチの開口は広げない**（プレート保持）
- M2 熱圧入インサート（外径 3.2）: ボス φ5.6 だと肉 0.46 で割れる → 壁と一体の角柱に。
  下穴はインサートより 1.0〜1.5 深く。外面に露出させない。PLA に M2 を直接ねじ込むと舐める
- ネジはキャップの縁より外に置き、**ドライバーが届くか**を検査する（キャップ 18mm 角は開口より 4mm 大きい）
- ホットスワップ基板は**固定が要る**（スイッチを抜く力がソケットのはんだに剥離力としてかかる）
- ゴム足は座ぐりより厚くないと接地しない。0.6mm 違うと傾きが 0.41° ずれる
- フィレットは「通った」のに体積が黙って欠けることがある → 前後で体積と max Z を比べる。面取りが安定
- USB メスは壁のすぐ内側に（奥にあるとプラグが届かない）。**穴を広げずにメスを壁へ寄せる**
- 樹脂のケースは電波を妨げない。導電性フィラメントでは刷らない

## 組み立ての検査（HHKB の gen_assembly が参照実装）

- **全部品（利用者が挿すケーブルも）を組み立てモデルに入れる。**入っていない部品は検査していない
- 部品ごとに**留め方（HELD_BY）と入れる経路（INSERT_PATH）を宣言**し、実形状でたどる。
  **留まるかと入れられるか・外せるかを同じ検査で見る**（電池蓋を 3 回作り直した）
- **面の取り合いは体積では見えない**（窪みと座ぐり）。矩形の重なりで別に数える
- 予約の箱と実形状は別の質問。箱×実物の組を外すなら「箱 ⊇ 実物」の検査を必ず置く
- 許容値が要るように見えたら、モデルが実物と違う（HHKB は 6 件とも許容 0 で解いた）
- 干渉は B-rep の総当たり＋結果の記憶（鍵は 2 立体の形のハッシュ・foundry/verify.py）
- 水平に噛む機構（庇・舌・溝）は、外形を共有する落とし込み蓋には原理的に入らない
- 組んだ瞬間だけでなく、持ち上げる・裏返す・打鍵するときも見る（ナットが落ちた）
- 利用者は文章より **.blend と断面図**で設計を理解した。生成したら自分でも断面を見る
