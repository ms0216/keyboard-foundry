# アンテナ（XIAO nRF52840）

HHKB open-gaps #23（2026-08-23 決着）・`decisions/2026-08-16-*antenna*`・`task-c3-ble-split.md`。

## 事実

- XIAO のアンテナは **USB と反対の端**の 3.5×1.5mm のチップ（TX と印字された側の縁から 7.0mm・
  中心から 1.9mm ずれている）。USB を奥面に出すとアンテナは必ず内側を向く
- Seeed の量産設計は、アンテナの縁から 1.30mm（外形から 3.14mm）だけ 4 層とも銅を抜いている。
  一般論の「全層 5〜10mm」はそれより緩い側。整合は直列 4.7nH＋シャント 0.5pF
- **外付けの GND 面が覆いかぶさるのは別の物理。**測って決める
- ピンソケットで XIAO を浮かせると、アンテナと地板の距離が変わる（浮き 0 → 7.22mm / 2.0 → 5.24 /
  10.5 → 0.72mm）。**ソケット構成の数字でアンテナを判定しない**
- 単3電池の至近（1.0mm）は論外。実測では横 5mm でも RSSI は変わらなかった → 要件 5mm
- 送信電力で塞がれたアンテナは直らない（+4dB に対し 20〜30dB）
- 受信感度 −96dBm（保守値 −90）。0.3m で余裕 60dB、2m で 44dB

## 基板の作法

- 禁止域は**塗られた後のベタ**で確かめる（ルールエリアを置いただけでは足りない）
- アンテナ真下の配線は遠い方の層へ。0 本を目指す
- 禁止域の縁に φ0.6 の GND ビアを 1.2mm 間隔で**4 辺とも**（「2 辺以上」と緩く書いた前科）
- 禁止域の位置が本物と合うか検査する（3.9mm 外して 450mm² の銅を捨てていた）
- RF は銅の実外形で測る（保守側に太らせた箱で測って余裕を 3 分の 1 に見積もった）

## 発注前に ¥0 で測る方法（HHKB で実施）

**知りたいのが「差」なら、差を作る物（金属）で模擬できる。**アルミ箔（表皮深さ 1.5µm）と
厚紙のスペーサで地板を模し、nRF Connect の RSSI で比べる。わざと実物より悪く作れば上限になる。

1. 距離 30cm に印、向き・高さ固定、スマホは台に置く、周りの金属と USB ケーブルの取り回しを固定
2. **基準（XIAO 単体）を 2 分見て、ふらつき幅を物差しにする**（HHKB は 7dB）。
   直近 30 秒で最大も最小も更新されなければ打ち切る
3. **同じ日・同じ場所で 1 変数ずつ足す**（日を分けた比較は無効）
4. 判定: 差がふらつき以内 → 問題なし / 〜10dB → 進む / 10〜20dB → 検討 / **20dB 以上 → 改版**
5. 長さを半分・実物・倍にして共振を見る（2.4GHz の λ/4 ≒ 31mm）。GND に繋ぐリード線は
   前後で導通を確かめる

HHKB の結果: 単体 −66〜−73dBm / GND 線 40・80・160mm で +3/+3/+1dB（共振なし）/
アルミ箔を数 mm で −7dB・約 2cm で −4dB / 電池 +1dB / 全部で **−7dB** → 発注した。
手を鍵盤に乗せて試す（人体は 2.4GHz を吸う）。アルミ缶で包むと劣化する。
使用距離は設計側が仮定しない（利用者が決める）。
