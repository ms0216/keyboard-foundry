# 部品（HHKB 分割機で確かめたもの）

**使う前に「効いた条件」が自分の機種でも同じかを読む。**HHKB の前提は
「乾電池（アルカリ）2 本・打ち止めでレール 1.8V・XIAO nRF52840・MX ホットスワップ」。
在庫と単価は 2026-08 時点——**発注前に `tools/kb <機種> parts` で取り直す。**
番号と選定理由の正本は [foundry/parts.py](../../foundry/parts.py)。

凡例: 【一般】キーボード一般 / 【XIAO】XIAO・ZMK / 【電池】乾電池駆動に効く

## 選び方（全部の部品に共通）

1. **効く条件を先に全部並べる。**動作電圧の下限・動作点での保証値・フットプリントが
   帯に入るか・在庫と代替・段取り費。1 軸（Basic か・安いか）で選ばない
2. **データシートの数字は最悪条件の値**（1A・40V など）で、動作点の値ではない。
   動作点で保証しているかを見る。曲線の外を推定して断定しない
3. JLCPCB は **Extended 1 種類につき段取り費 $3**（Preferred は $0）。HHKB では部品代の
   4 割がこれだった。**効くのは段取り費で、単価ではない。**基板は 5 枚単位
4. 実験用に別品番を買わない。**本番の品番を決めてから買う**
5. 型番で買う（「単3×2 の箱」と書いて横並び型を買った）

## スイッチ・スタビ・キーキャップ【一般】

- **MX の見分けは高さ**（MX 約 14mm・低背約 8.8mm）。「MX 互換」はステム形状と端子位置の
  別々の意味で使われる（Choc V2 は十字ステムだが刺さらない）。3 ピンも 5 ピンも可
- スタビ（Cherry・PCB マウント）: **2 / 2.25 / 2.5 / 2.75u は同じ 2u 部品**（支点 ±11.938、
  穴 φ3.048 / φ3.988）。**3u は国内で買えなかった**（遊舎・TALP・Amazon・海外 4 店）→
  配列を決める前に入手性を確かめる。スペースのスタビは**ワイヤ奥（180°）**
- キーキャップの高さは**プロファイル名ではなく SKU に書かれた高さ**で判断する
  （TALP の「XDA」は約 8.5mm で通説と 0.6mm 違った）。SP 直販で 1 個単位の実測サンプル可

## XIAO nRF52840【XIAO】

- 技適 211-220207。GPIO は D0〜D10 の 11 本、**ADC は D0〜D5 だけ**
- **BAT 端子に乾電池を繋がない**（LiPo 充電回路直結。USB を挿すと一次電池を充電する）。
  電池は **スイッチ → ショットキー → 3V3 ピン**
- 基板上の RGB LED は 1 パッケージ（赤 P0.26 / 緑 P0.30 / 青 P0.06・共通アノード）。
  赤＋緑で橙に見える
- 3V3 に 2.2µF×5 を内蔵（Seeed の KiCad ソースを機械で数えた）。LDO の C_OUT 規定は 0.1〜10µF
- 2022-09 以降ヘッダは付属しない。ピンソケットで浮かせるとアンテナが地板に近づく（[rf-antenna.md](rf-antenna.md)）
- 60% 配列の本体基板には置く場所が無く、子基板＋FFC にして USB-C を奥へ出した（HHKB の構成）
