# 電源と回路（乾電池・XIAO nRF52840）

HHKB 分割機で実測・データシートで確かめたこと。出典は HHKB の
`docs/hardware/electrical-design.md`・`decisions/2026-08-16-*.md`・`task-c4-c5-power.md`。

## 電源経路

```
電池 +  →  スライドスイッチ  →  [分圧 1MΩ+1MΩ → D0/AIN0]  →  ショットキー B5819W  →  XIAO 3V3
```

- **BAT 端子に繋がない**（LiPo 充電回路直結。USB を挿すと一次電池を充電・液漏れ・破裂）
- ショットキー 1 個で逆流防止と USB 接続時の自動切り離しを兼ねる。USB と電池を同時に
  繋いで +0.8µA（放電向き）。逆漏れの最悪は**消耗した電池**のとき
- 分圧は**スイッチの後ろ・ショットキーの手前**。USB 給電中も電池そのものが読める。
  3V3 側のコンデンサの電荷は分圧側へ流れない
- 理想ダイオード（P-MOSFET・LM66100）は**成立しなかった**: 「電位差ほぼ 0 でも逆流 0」は
  ショットキーにしかできない（LM66100 の遮断保証は逆流 0.5A から）。**この結論は
  「VBUS を渡せない」という構造に乗っていた——構造が変わったら読み直す**（#32 は前提が
  消えたのに 5 日間止めていた。再評価したら追加部品ゼロで成立した）
- 電池の + を基板へ往復させない（リード線なら直結）

## 打ち止め電圧

**打ち止め = max(動き続ける下限 + Vf, 起動できる限界 + 余裕)。**

| 下限 | 値 |
|---|---|
| nRF52840 | 1.7V（+ 余裕 0.1）＝ レール 1.80V（HHKB ではこれが律速） |
| 74LVC595 | 1.10V（74HC595 なら 2.0V で規格外） |
| マトリクス | BAT46W 0.30V ÷ 0.3（VIH = 0.7VDD）＝ 1.17V |
| ホットスワップソケット | 2.0V DC（**未検証の制約**） |

- **起動できる電圧は、動き続けられる電圧より高い。**維持 1.95V に対し起動は直列 10Ω で
  2.15〜2.25V、25Ω で 2.42〜2.70V（確率的）。**スリープ復帰も起動と同じ手順**
- 冷えるとアルカリの内部抵抗は 2〜3 倍になり「寒い朝だけ点かない」。冷蔵庫で 2h 冷やして測れる
- 打ち止め近くでは静かに止まらない: レール 1.86V で CPU は動くが無線がリンクを張れず、
  走査と広告で 2.7mA（6 倍）を食い続ける → **自分から soft off する**（firmware/）
- nRF52840 はレール 1.7V 未満でブラウンアウトを繰り返し、NVMC の書き込み（VDD ≧1.7V が
  条件）でペアリング情報が壊れうる
- リチウム一次（FR6/L91）2 本は 3.6V で nRF の推奨上限ちょうど → 禁止と説明書に書く

## バルクコンデンサ（要るかの判定順）

1. **まず C を考えずに I·R を計算する。**余裕に収まれば容量は 0 でよい
2. 収まらないときだけ C = バースト長 ÷ R を考える

実測: BLE の最大 10.22mA（広告＋スキャンが重なる分割セントラル。広告だけだと 8.02mA）×
打ち止め付近の内部抵抗 9.2Ω = 94mV（余裕 300mV）。1ns 分解能・60 万点で µs 級の尖り 0 個
→ **100µF は削除した。**載せていたときは深いスリープ（約 2µA）中に電荷が抜けず、
電源を切って入れてもリセットされない不具合（53 秒）を作っていた。バルクが効くのは
CR2032 のような高抵抗・低電流のときだけ。バルクとパスコンは兼ねられない
（100µF/1206 の自己共振は約 0.5MHz、0.1µF/0805 は約 19MHz）。

## パスコン

**効くのは直線距離ではなく、IC → パスコン → GND → IC と戻るループの配線長**（インダクタンス）。
電流は全供給元からループ L に反比例して分流する（直近の C_U1 と FFC 越しで 58:1）。
**負荷の直近にいないパスコンは誤差にしかならない**（HHKB で 2 個削除）。検査は配線後の
銅箔の経路長で行い、GND 側の戻り（ビアの数）も数える。モジュール（XIAO）は内部に
持っているので外付けは重複。LDO には出力容量の上限もある。

## キースキャン

- **行×列マトリクス＋キーごとに 1 ダイオード、行は MCU 直結の入力、列だけをシフトレジスタで**
  （ZMK 公式の推奨）。行が直結なら割り込みで起きられ、常時スキャンが要らない
- チャーリープレックスは**成り立たない**: VIH 0.7VDD・VIL 0.3VDD では本物のキーとゴーストの
  Vf の条件が両立しない（HHKB で基板発注前に破棄）
- 595 の MR（10 番）は VCC、OE（13 番）は GND。浮かせない。数珠つなぎは Q7'（9）→ DS（14）
- **595 を 1 個惜しんで論理配置を歪めない**（90mm の配線が 4 段を横断した。1 個約 30 円）
- 同時押しの逆漏れ: BAT46W で 60℃・同じ行 5 個以上は余裕を割る（25℃ なら 9 個でも可）
- 行列の目安: 押している間だけ 1 キー 0.14〜0.21mA（列 High → スイッチ → ダイオード →
  行のプルダウン）。待機 0

## 電流の目安（左＝分割セントラル・2000mAh 換算）

電流 ≒ 0.090 + 2.591 ÷ 分割間隔[ms] + 2.725 ÷ (ホスト間隔[ms] × (latency+1)) [mA]
（5 構成の予測がすべて実測と 0.01mA 以内）。スリープ中 2〜3µA。30 分でスリープなら
約 16 ヶ月、スリープ無しで約 5 ヶ月。**寿命を決めるのはセントラル側。**詳細は
[zmk-and-xiao.md](zmk-and-xiao.md)。
