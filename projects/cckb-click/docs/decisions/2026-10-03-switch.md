## 1. なぜ決める必要が生じたか

cckb-click は「薄い表面実装のスイッチを JLCPCB に実装してもらい、軸の無いキャップで押す」方式。キャップ・枠・柱の
高さは全部スイッチの寸法（本体 2.5・ステムの上面 3.4±0.2・ON まで 0.3±0.2）から決まるので、形を作る前に品番が要る。

## 4. 影響範囲（力の流れに沿って）

指 → キャップの上面 → キャップの下面（押す面）→ ステム → ドーム → 端子 → 基板のランド → 基板 → 柱 → 枠。

- ステムの上面 3.4±0.2 → 押す面 3.6（決定記録 2026-10-03-structure）→ つばの厚さ・くぼみの深さ・枠の下面・柱の高さ
- ON まで 0.1〜0.5 → 押し切りでキャップが下がる量 → キャップが枠から出る量 1.0・幅の広いキーの傾き
- 作動力 0.3〜0.9 N が基板を押す → 基板のたわみ → 隣のスイッチの誤動作（open-gaps #4）→ 柱の間隔
- ランド 8.5×5.0 → キーごとのダイオード・柱・つばの逃げと取り合う（基板の段）
- 62 個のスイッチの戻す力 0.1 N → キャップと穴の隙（擦れたら戻らない）

## 5. 決めたこと

- **SKRAAWE010（JLC C202383）を本番の品番にする。**在庫があり、利用者が静かな側として選んだ
- 基板のランドは SKRACAE010 も載る形にする（ランドが同じ 8.5×5.0。CAE は移動量の公差が半分・寿命 2.5 倍で、在庫が戻れば替えられる）。
  **ただし CAE はステムの上面が 0.1 高い（3.5±0.2）。**いまの押す面 3.6 のままだと公差の端（3.7）で 0.1 押しっぱなしになるので、
  CAE に替えるときはキャップか枠を刷り直して押す面を上げる（基板は同じでよい。試し刷りの台 3.7 がこの端に当たる）
- Panasonic EVQQ2 を同じ基板に載せられるか（ランドを重ねる）は、はんだ付けできるかを基板の段で確かめてから

## 検討して捨てた案

| 案 | 捨てた理由 |
|---|---|
| Omron D2LS-21（販売者と同じ系統のマウス用スイッチ） | 音が大きい（販売者の記事）。単価 2.6 倍 |
| SKRACAE010 を本番に | JLC の在庫が 0（2026-10-03） |

## この決定が乗っている前提（**動いたら読み直す**）

- JLC の在庫（C202383 がある・C54897500 が無い）
- AWE と CAE のランドが同じ（外形図を見比べた。基板の段でフットプリントを作るときに数字で突き合わせる）。ステムの高さは違う（上）
- 「AWE は静か」は実物で確かめていない（仕様書に音の規格値が無い）
