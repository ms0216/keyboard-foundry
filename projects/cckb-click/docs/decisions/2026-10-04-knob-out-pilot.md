## 4. 影響範囲（力と信号の流れに沿って）

- **スイッチの位置 → 足跡 → 電池の＋（VBAT_IN）の最後の区間・VBAT_SW の縦の区間と C_BAT の枝・枠のランド 4 つの GND のビア → 角の GND の縫いのビア**。
  どれも決まった形で引く線（click_routes）なので、足跡と一緒に 0.75 動いた。長い線（VBAT_SW・263 mm）は右の端が 0.75 延びただけ。
  SPI・595 どうし・電源の枝（左手前）は置き直しで、変わらない
- **スイッチの位置 → JLC の規約 → 頼み方**: 2.5 mm を満たさないので、JLC が載せないと言うことがありうる。そのときは手はんだ（docs/order-steps.md の冒頭）
- **スイッチの位置 → 枠の逃げ・切り欠き・厚い屋根 → 壁の強さ**: 切り欠きの内側の面は本体の縁 ＋ 0.4（枠の外面から 1.65）。切り欠きの形は v2 の B と同じ
- **指 → 切り欠き → つまみ → スイッチの本体 → はんだ（端子 3・枠 4・突起 2）→ 基板**: つまみを動かす力（最大 2.45 N）は基板が受ける（前と同じ）。
  ランドと基板の縁の間は 1.70（前は 2.45）
- **下穴 → ねじ山の掛かり → 壁の内側の肉 → キーの穴 → キャップ**: 穴の位置は変えていない。肉は 0.1 増えた。ねじが押し広げる樹脂は増える
  （ねじの外径の外の壁 0.6／0.39 は同じ）
- **下穴 → 試し刷り（ねじ・角・v2）**: どれも本番の枠から切り出すので、下穴と切り欠きが新しい形になる（v2 は、刷った物と同じ形を出し続けるように、
  位置を本番から測り直した: (i) = 本番から 0.75 内・(ii) = 本番）
- **蓋 → 枠の口のまわり・基板の穴 H30・H31**: 蓋を刷る物から外しただけ。枠のひさし・溝・指の切り欠き・基板の穴は前のまま

**薄い壁の下穴を補正しない理由**: 薄い壁（幅の広いキーの脇の H16・H17・H18）では、刷る線が設計より 0.04〜0.05 内へ寄る（壁が線 1 本になるため）。
φ1.6 は線で 1.49〜1.50 になる。これは、利用者が v2 で「薄い壁でも問題なし」とした切れ端（線で 1.50）と**同じ径**で、入れ始めが固かった φ1.5（線で 1.44／1.40）ではない。
補正して φ1.65〜1.7 にすると、利用者が確かめていない組み合わせになり、ゆるい側へ寄る（ゆるい穴は直せない・きつい穴はドリルで広げられる）。
`tools/slice_main.py` が、本番の枠の 22 個を G-code で測って、利用者が確かめた径（1.54 ± 0.03／1.50 ± 0.03）から外れたら NG を出す。

## この決定が乗っている前提（動いたら読み直す）

- **JLC の規約の「2.5 mm」と Economic の「0.3 mm」は 2026-10-04 に読んだ値**（出どころは docs/order-steps.md §2-1）。JLC が実際にどう扱うかは、注文してみるまで分からない
- 電源スイッチは MSK12C02（本体 8 × 2.8・つまみの出 1.45・行程 1.6）。**つまみの出は図面の名目**（置くずれ・基板の外形の公差 ± 0.2 は見ていない）。
  **つまみの出の公差（4 回目の監査 2026-10-04 で直した）**: MSK12C02 の図面（LCSC C431540・2024-12-14）は、つまみの出 1.45・中心から先まで 2.85 に**個別の公差を書いていない**。表題欄の未注の公差は X.xx = ± 0.2（± 0.1 はつまみの幅 1.3・本体の幅 2.8・突起 φ0.75 だけ）。**前の記録の「± 0.1」は誤り → ± 0.2**。出どころ: 図面を自分で開いて読んだ（datasheet.lcsc.com の PDF 1 頁目の表題欄。2026-10-04）。**最悪の場合**: 基板の縁に対して 0.30 − 0.20 − 0.075（φ0.75 の突起と φ0.9 の穴の遊び）= **+0.025**（細い突起 φ0.65 なら −0.025）= 先は**実質、基板の名目の縁まで届きうる**。枠の外面に対して 0.60 − 0.20 − 0.075〜0.125 − 0.1（ねじ穴の遊び）− 0.1（刷りの誤差）≒ **+0.10〜+0.13** = 枠の外へは出ない。
  **利用者の選択肢（まだ決めていない）**: スイッチを 0.2 内へ戻す（先は基板の縁の 0.50 内）と余裕は戻るが、利用者が触って選んだ位置から離れる。
- ねじは**ふつうの M2×4 の小ねじ**で試した（買う物の表のスリムヘッドではない。ねじ山は同じ M2 並目）。掛かりの長さ 2.4
- 刷り方は 0.4 ノズル・層 0.1・Bambu PLA Basic（下穴の線の径は、この設定での値）
- `pcb/freerouted.json` は板 4dc68901… から写した物のまま（左手前の配置は変えていない）
- 利用者の指は 1 人ぶん。指先の球（半径 7.5）は物差し
