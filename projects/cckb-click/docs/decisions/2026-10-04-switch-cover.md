# 電源スイッチを内側へ・電池の蓋（差し込み式）・蓋のねじ穴を取っておく

- **日付:** 2026-10-04
- **状態:** 決定（**直した板は、まだ独立に見直していない**: open-gaps #35。**角の試し刷りはまだ刷っていない**: #34）
- **決めた人:** 利用者（下の 4 つ）。寸法と形は Claude（刷って直す値は `[暫定]`）

利用者の決定（2026-10-04・下調べの絵 build/cckb-click/study/s1〜s3 を見て）:

1. **電源スイッチを内側へ動かす**（つまみを外へ出さない = 鞄の中で勝手に切り替わらない・JLC の Economic で載る）。枠に爪を入れる切り欠き
2. **蓋をねじで留める日のための穴を 2 つ、基板に取っておく**（既定では使わない）
3. **電池の蓋は差し込み式**（枠だけで留まる・道具なし）。蓋が無くても同じに使える。厚さ 8.1 のまま・外形から出ない・ねじ 20 本を外さない
4. 電池は **CR1632 のまま**。載せないコンデンサのランド 2 つも残す

  JLC の実装の規約は「部品の本体と基板の縁は 2.5 mm 以上」で、載るかは注文してみないと分からなかった（open-gaps #31・D4 の「手はんだにするか」）。
  鞄の中で引っ掛かって勝手に切り替わるおそれもあった（P8）
- 電池の口は開いたままで、電池の縁（＋の缶）が手前の壁の口から 1.71 奥に見えていた

## 4. 影響範囲（力と信号の流れに沿って）

- **電池 ＋ → クリップの左右のランド → 電源スイッチの共通の端子 → 入の端子 → VBAT_SW の長い線 → TP_VSW・D_PWR・分圧**。
  スイッチを動かしたので、VBAT_IN（＋）と VBAT_SW の右の端を引き直した。**VBAT_IN は決まった形にした**（前は Freerouting）。
  C_BAT はスイッチのランドに近づくので 1.0 左へ（VBAT_SW の縦の区間に横で繋がるのは同じ）
- **Freerouting は同じ入力でも引くたびに形が変わる**（前の監査の所見）。角だけ直すのに SPI・電源の枝が変わらないよう、
  監査した板の線を `pcb/freerouted.json` に写して置き直すようにした（`route_click.py --freeroute` で引き直せる）
- **指 → 切り欠き → つまみ → スイッチの本体 → はんだ（端子 3・枠 4・突起 2）→ 基板**。つまみを動かす力（最大 2.45 N）は基板が受ける。枠には掛からない
- **蓋 → ひさし（上）・切り欠きの壁（左右）・奥の壁（奥）・山と溝（手前）→ 枠**。基板には触れない（下の隙 0.1）。電池にもクリップにも触れない
- **蓋のねじ穴 → 電池を抜き差しする道の下**（表の銅は元から無い）。裏は頭の円の中の銅を抜いた（ほかのねじと同じ）。
  電池クリップの足跡のコートヤードは、口の側の両脇を欠いた（そこはクリップの板の端が基板の 3.7 上に張り出すだけで、基板の面には何も無い）
- **JLC の頼み方**: スイッチは縁の規則を満たすので、「電源スイッチだけ手はんだ」の案は要らなくなった（docs/order-steps.md §2-1）。
  Economic か Standard か（リフローの温度）は残る
- **試し刷り**: スイッチの位置は基板で決まり、発注後は直せない。だから発注の前に、角の試し刷りで爪が届くかを見る（#34）

### 蓋（`cover_battery.stl`）

L 字。手前の板（厚さ 1.2・口を塞ぐ）＋ 上の板（厚さ 0.7・付け根 1.15）。手前の板の上の両端が腕（長さ 5.5・太さ 0.7）で、先の山（掛かり 0.25）が溝に入る。
上面の手前寄りに、爪を掛ける溝（幅 9）。**手前の面をベッドに刷る**（腕がベッドの面の中で曲がる）。引き抜く力の見積もりは約 1.6 N（計算だけ）。

## 検討して捨てた案

| 案 | 捨てた理由 |
|---|---|
| つまみを外へ出したまま（前の形） | JLC の規約に当たる・鞄で切り替わる |
| 上向きのつまみのスイッチ（MSS12C02 系）を枠の上面の長穴から | 利用者が案 1b（同じ部品を内側へ）を選んだ。部品を替えない |
| 切り欠きの内側を薄い垂れ壁（厚さ 0.5〜0.6）で塞ぐ | 爪で押すと根元が積層を剥がす向きに曲がる（5 N で 30 MPa 前後）。屋根を厚くする方が強くて刷りやすい |
| 蓋のばねを、上の板の脇（滑る向き）に付ける | 長さが 4.4 しか取れず、ひずみが 1.9 % になる |
| 腕を長さ 6.5・太さ 0.9 に | 手前の板の下半分が、真ん中の幅 3.3 の柱だけで繋がる。5.5 にして柱を 5.3 に |
| 山を手前の板の真ん中（厚さの中ほど）に | 溝の手前に残る肉が 0.2 しか無い。奥へ寄せて 0.4 |
| 蓋を基板の穴にねじで留める | 利用者が「枠だけで留まる・道具なし」を選んだ。穴だけ取っておく |
| 角だけ Freerouting で引き直す | 引くたびに SPI・電源の枝の形が変わり、監査した配線でなくなる |

## この決定が乗っている前提（動いたら読み直す）

- 電源スイッチは MSK12C02（本体 8 × 2.8・つまみの出 1.45・行程 1.6）。**部品を替えたら、本体の縁・切り欠き・角の試し刷りを全部見直す**
- JLC の規約の「2.5 mm」は 2026-10-04 に読んだ値。名目でちょうど 2.50（本体の幅の公差 ± 0.1 の半分と、置くずれは見ていない）
- 電池クリップは MY-1632-03-R・電池は CR1632（φ16 × 3.2）。蓋の手前の板の隙 0.51 は、止めに当てた電池の位置（図面から）に乗っている
- 枠の上面 5.0・クリップの上 4.1・口の上の壁の下面 3.6
- 刷り方は 0.4 ノズル・層 0.1（腕の太さ 0.7・溝の手前の肉 0.4 は、線の幅 0.42 が前提）
- `pcb/freerouted.json` は板 4dc68901… から写した。**左 Shift のまわり（595・パスコン・分圧）の配置を変えたら、置き直せなくなる**（`--freeroute` で引き直して監査し直す）

## 覆す前に読むこと

- 基板の上の物（スイッチの位置・蓋のねじ穴）は発注後に直せない。枠と蓋は刷り直せる
- 蓋のねじ穴にねじを入れる設計をするときは、ねじの先（基板の上 2.4）と電池の道・クリップの板（基板の 3.7 上）を、そのとき立体で見る（いまは検査していない）
