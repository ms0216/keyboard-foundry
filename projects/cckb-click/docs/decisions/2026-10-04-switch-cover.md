## 4. 影響範囲（力と信号の流れに沿って）

- **電池 ＋ → クリップの左右のランド → 電源スイッチの共通の端子 → 入の端子 → VBAT_SW の長い線 → TP_VSW・D_PWR・分圧**。
  スイッチを動かしたので、VBAT_IN（＋）と VBAT_SW の右の端を引き直した。**VBAT_IN は決まった形にした**（前は Freerouting）。
  C_BAT はスイッチのランドに近づくので 1.0 左へ（VBAT_SW の縦の区間に横で繋がるのは同じ）
- **Freerouting は同じ入力でも引くたびに形が変わる**（前の監査の所見）。角だけ直すのに SPI・電源の枝が変わらないよう、
  監査した板の線を `pcb/freerouted.json` に写して置き直すようにした（`route_click.py --freeroute` で引き直せる）
- **指 → 切り欠き → つまみ → スイッチの本体 → はんだ（端子 3・枠 4・突起 2）→ 基板**。つまみを動かす力（最大 2.45 N）は基板が受ける。枠には掛からない
- **蓋 → ひさし（上）・切り欠きの壁（左右）・奥の壁（奥）・山と溝（手前）→ 枠**。基板には触れない（下の隙 0.1）。電池にもクリップにも触れない
- **蓋のねじ穴 → 電池を抜き差しする道の下**（表の銅は元から無い）。裏は頭の円の中の銅を抜いた（ほかのねじと同じ）。
  電池クリップの足跡のコートヤードは、口の側の両脇を欠いた（そこはクリップの板の端が基板の 3.7 上に張り出すだけで、基板の面には何も無い）
- **JLC の頼み方**: スイッチは縁の規則を満たすので、「電源スイッチだけ手はんだ」の案は要らなくなった（docs/order-steps.md §2-1）。
  Economic か Standard か（リフローの温度）は残る
- **試し刷り**: スイッチの位置は基板で決まり、発注後は直せない。だから発注の前に、角の試し刷りで爪が届くかを見る（#34）

## 検討して捨てた案

| 案 | 捨てた理由 |
|---|---|
| つまみを外へ出したまま（前の形） | JLC の規約に当たる・鞄で切り替わる |
| 上向きのつまみのスイッチ（MSS12C02 系）を枠の上面の長穴から | 利用者が案 1b（同じ部品を内側へ）を選んだ。部品を替えない |

## 3 回目の監査（差分・2026-10-04）と直し

直した板（fe90b1e6…）と角の枠・蓋を、前の板（4dc68901…）との差分で独立に見た。**基板は致命 0・重要 0。板は変えていない**（sha256 は同じ）。
重要 1 件は刷る蓋で、直した。軽微は記録だけ（open-gaps「軽微・承知しているもの（3 回目の監査）」）。

### 重要: 蓋のばねのひずみ（直した）

- **何が違っていたか**: ひずみの式 ε = 1.5·t·δ/L² に、腕の全長 L = 5.5 を入れていた。山は腕の先の 1.5（口の上の壁の下いっぱい）にあり、
  壁の下面は平らなので山の全体に当たる。たわんだ腕は先へ下がるから、**最後まで当たっているのは山の、付け根の側の端**（付け根から 4.0）。
  正しくは 1.5 × 0.7 × 0.25 ÷ 4.0² = **1.64 %**（許容 1.0 % を超える）。記録の 0.87 % は、効いていない長さで出した数だった
- **型**: 式に入れた寸法が、作った立体の寸法ではなかった（自分の定数どうしの一致 = 作法 3）。いまは `click_case.cover_detent` が
  蓋を手前へ 0.1 ずつ引いて**枠と蓋の立体の重なり**を取り、たわむ量・当たる所・付け根・太さ・幅・隙間を全部そこから測る

- **決めたこと**: `COVER_ARM = (6.3, 0.7, 0.5)`・`COVER_BUMP = (0.25, 0.8, 0.8)`（3 つ目 = 山の、腕に沿う長さ）。枠は変わらない（STL は前と同じ。溝は壁の幅いっぱいのまま）
- **山を越えるとき**の腕の先の下がりは 0.31（腕の下の隙間 0.5 に収まる）
- **代わりに払ったもの**: 真ん中の柱が幅 5.3 → 3.7（厚さ 1.2・高さ 1.6）。手前の板の下の端の角を 5 N で奥へ押すと、柱のねじりは約 28 MPa（前は約 18。目安の上限 38。
  式で置いた値）。蓋は枠の面と面一なので、指で下の角だけを押し込むことは起きにくい。**刷って、柱が白くならないかも見る**（P21）
- **刷れるか（G-code で数えた）**: 腕は 11 層のうち 10 層が幅 0.42 の線 2 本（中心の間 0.34 = 刷り上がりの太さは約 0.76。その太さならひずみ 0.94 %）・
  1 層目だけ面取りで細く、幅 0.5 の線 1 本。山は各層で長さ 0.35〜0.44 の線 1 本（山の頂の線は腕の線から 0.38 = 山の高さ 0.40 のうち 0.38 が線になっている）。
  Bambu Studio 2.8.2 と OrcaSlicer 2.4.2 で同じ
- **許容 1.0 % の出どころ**（spec.PLA_STRAIN_LIMIT のコメントと同じ）: Bambu PLA Basic の TDS の曲げ強さ 76 MPa ÷ 曲げ弾性率 2750 MPa = 2.76 % の 0.36 倍。
  **曲げの値を使う**: 腕は曲げで使い、ひずみも曲げ試験と同じ梁の式で出しているので、同じ物差しどうしで比べられる。
  引張強さ 35 MPa ÷ 2750 = 1.27 % で見ると、1.0 % はその 0.79 倍（1 回で切れる値よりは下）だが、手引きの繰り返しの係数 0.42 倍（0.53 %）よりは上。
  **だから「何回もつか」は計算では言えない**。角の試し刷りで 20 回抜き差しして、腕が白くならないかを見る。TDS の数は監査が挙げた物で、今回取り直してはいない
- **検査**: tests/test_cckb_click_case.py `test_the_cover_spring_strain_is_measured_from_the_solids_...`。spec を直す前の値（腕 5.5・山 1.5）に戻すと
  「0.0164 <= 0.01」で落ちることを見た。前の式（全長 5.5 で 0.87 %）なら通っていたことも同じ検査に書いた
