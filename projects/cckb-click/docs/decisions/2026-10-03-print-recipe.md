# 刷り方: 精度を最優先にした設定・ノズル・最初に刷る最小の一式

- **日付:** 2026-10-03
- **状態:** 決定（最初の 1 枚の刷り方）。数値は刷った結果（docs/coupon-test.md の測る表）で直す
- **決めた人:** 利用者（最小の一式から刷る・精度を最優先にする）／設定の中身と形の変更の案は Claude

## 1. なぜ決める必要が生じたか

販売者は「少しのバリで作動不良を起こす」「3D プリントだとバリとか造形カスが 10% くらいの確率で発生して動作不良」と書いている
（記事 acc-introduction）。「0.3 mm 程度でキーが反応するので、少しでも変形したりしていると使用できない」（記事 order-acc）。
これまでの試し刷りは「0.20mm Standard」を既定のまま使う前提で、速さ寄りだった。利用者の決定（2026-10-03）:
**精度を最優先にする。最初は最小の一式（穴 3 つの枠・キャップ 3 個・板）だけを刷る。**

**CLI は設定の継承をたどらない（今回見つけた）。**Bambu の設定ファイルはほとんどの値を親に持つ。そのまま CLI に渡すと、

構造の決定記録に書いた「上 4 層・外周 2 本・Arachne」はこの既定値だった。**親をたどって 1 枚にしてから渡し、G-code の設定の欄と突き合わせる**
ようにした（tools/slice_precise.py）。foundry.slice_check は直していない（open-gaps #22）。

| 形・設定 | キャップ（滑る面にある数／全部） | 枠の穴 |

スライサーの設定だけでは、継ぎ目を滑る面から外せなかった。**形の側に溝を掘る**と、そろえる設定が溝の入隅を選ぶ。

**外の資料**

- OrcaSlicer の wiki（quality_settings_wall_and_surfaces）: 内→外→内（Inner/Outer/Inner）は「best external surface finish and dimensional accuracy」。
  外→内（Outer/Inner）は同じ精度だが「z seams will appear less consistent」。内→外は外周が内周に押されて「slightly reduced surface quality」
- 0.2 ノズル（Bambu の販売ページの記載・検索結果から）: 細かい造形向け。ラメ・マーブル・木・石・金属入り・PA・TPU・カーボン入りは不可
- Bambu の wiki は取得できなかった（HTTP 402）。ノズルごとの層・線幅・吐出の上限は、**同梱の Bambu の設定ファイル**から読んだ

## 4. 影響範囲（線が出てから指に触れるまで）

フィラメント（湿り）→ ノズル（径・温度）→ 線（幅・層）→ 外周（順・継ぎ目）→ 1 層目（つぶれ・太り）→ 面（押す面・掛かる面・滑る面）→
組んだときの隙 → スイッチの戻す力 0.1 N で戻るか。

- 層 0.2 → 0.1: 斜めの面（下の縁の面取り 0.3・上の縁の面取り 0.8）の段が半分になる。1 層あたりの吐出が半分 → 継ぎ目のこぶも小さい。時間は約 2 倍
- 層を spec.PRINT_LAYER に持たせた。機能する面は「1 層目 ＋ 層の倍数」（P.on_layer）。いまの高さは 0.2 の倍数のままなので、どちらの層でも成り立つ
- 継ぎ目の溝 → キャップの奥の縁に幅 2.0 の切れ込みが**上から見える**。穴の奥のリブがそこだけ 0.5 薄くなる（2.0 → 1.5。穴 +0.2 で 1.3）。
  奥の列の穴では、溝の上に柱が 0.3 × 2.0 だけ張り出す（刷る向き。小さな橋）
- 0.2 ノズル: 線が半分 → 角の丸まり・こぶ・糸が小さい。吐出の上限 2 mm³/s → 時間 2.2 倍。フィラメントの制限
- プレートが Textured PEI: 押す面（キャップの下面）と枠の上面がざらざらになる。平らさは変わらない前提。**まだ**（刷って見る）

## 5. 決めたこと

**プリンタ: A1 mini。**0.2 ノズルの設定があるのは A1 mini だけ。利用者の Bambu Studio も A1 mini で使っている。

**設定（print/cckb-click_precise_n04.json・n02.json。土台は Bambu の High Quality）**

| 設定 | 0.4 ノズル | 0.2 ノズル | なぜ |
|---|---|---|---|
| 土台 | 0.12mm High Quality @BBL A1M | 0.10mm High Quality @BBL A1M 0.2 nozzle | Bambu が「速さと加速度を下げて品質を上げた」と書いている組。自分で速さの数字を作らない |
| 層の高さ | 0.1 | 0.1 | 形が 1 つで済む。0.4 ノズルの下限 0.08 の内・0.2 ノズルの既定 |
| 1 層目 | 0.2 | 0.1 | 土台のまま。機能する面は 1 層目より上の境目にある |
| 線の幅（外周／1 層目） | 0.42 / 0.5 | 0.22 / 0.25 | 土台のまま |
| 外周の数・順 | 3・内→外→内 | 4・内→外→内 | 外周を内周に押させない（wiki）。継ぎ目も揃う。3 本以上が要る |
| 壁の作り方 | Arachne | Arachne | 0.8 の壁に 0.4 ノズルで線を 2 本出す |
| 外周の速さ・加速度 | 60 mm/s・2000 | 60 mm/s・2000 | 土台のまま |
| 継ぎ目 | そろえる（Aligned）＋形の溝 | 同じ | 上の表。スカーフ継ぎ目は使わない（継ぎ目を斜めに長く伸ばして滑る面に広げる。結果を機械で確かめられない） |
| 象の足の補正 | 0 | 0 | 形の面取り（キャップ 0.3・穴 0.4）で逃がす。補正を入れると測る塊の実測が素の機械の値でなくなる |
| X-Y 補正（穴・外形） | 0 | 0 | **測ってから入れる**（測る表 → 戻す所） |
| 円弧 | 入 | 入 | 土台のまま（Bambu の機械向け） |
| 壁をまたがない移動 | 入 | 入 | 島の間の糸を滑る面に落とさない |
| ブリム・サポート・スカート | 無し | 無し | 縁にバリを残さない |
| アイロンがけ | 無し | 無し | 上面は機能しない面。最初の 1 枚は変える物を減らす。見た目が気になれば足す |
| 上・下の層 | 7・5 | 7・5 | 0.10 の Bambu の設定と同じ。中は 15% |
| 刷る順 | 層ごと（全部一緒） | 同じ | 1 個ずつだと層の時間が短くなり、熱で垂れる |
| プレート | Textured PEI（65℃） | 同じ | A1 mini の付属の板。記録にあった板の種類。違う板なら選び直す |
| 置き方 | 真ん中・回さない | 同じ | 長い辺と穴を広げる向きが X（頭）。測る塊の X / Y がそのまま機械の X / Y |

**形の変更**

- `PRINT_LAYER` 0.2 → 0.1、`PRINT_FIRST_LAYER` 0.2 を spec に。**押す面 3.6・つば 0.4 は変えない**（下の「捨てた案」）
- `SEAM_NOTCH` = 幅 2.0 × 深さ 0.5 の継ぎ目の溝を、キャップの胴の奥の面と、枠の穴の奥の壁の真ん中に（`[暫定]`。見た目は利用者が決める）
- 最小の一式 `min`（coupon_min_plate ほか）と、測る塊・測る穴

**刷る前にプリンタ側ですること**: 印刷を送る画面で「ベッドレベリング」と「流量ダイナミクスのキャリブレーション」を入れる（A1 mini が自動で測る）。
フィラメントを乾かす。0.4 ノズルで流量のキャリブレーションをしていなければ、測る表でずれが 0.1 を超えたときにする。

## 検討して捨てた案

| 案 | 捨てた理由 |
|---|---|
| 層 0.1 を使って押す面を 3.5・浮きを 0.1 にする（つば 0.5） | 公差の端のスイッチ（ステム 3.6）を 0.1 押しっぱなしにする。要求 R1 と構造の決定（押しっぱなしは誤入力・浮きは感触）に反する。検査が落とす。浮きを詰めたくなったら standin の小片で触ってから |
| 層 0.08 | くぼみ 1.0・柱 3.0 が境目に乗らない |
| K1 Max | 0.2 ノズルの設定が無い。利用者のスライサーは A1 mini |
| 継ぎ目を「奥（Back）」 | 奥の平らな辺の端（角の丸みの始まり）に出た。CLI の自動配置が物を 180° 回すと奥が逆になることも分かった |
| 継ぎ目をスライサーの画面で塗る | 手作業で再現できず、プリセットに入らない |
| スカーフ継ぎ目 | 上の表の「継ぎ目」。溝で足りなければ次に試す（両方のスライサーに設定はある） |
| 外→内 | 精度は同じだが継ぎ目がばらつく（wiki） |
| 象の足の補正 0.1〜0.15 を足す | 形の面取りと二重になり、1 層目が 0.3〜0.4 引っ込む。測る塊の値も変わる。刷って太りが面取りを超えたら入れる |
| 板だけ粗い設定で別に刷って時間を詰める | 2 枚に分かれ、準備が 2 回になる。板の台の高さ 3.4 も機能する面 |
