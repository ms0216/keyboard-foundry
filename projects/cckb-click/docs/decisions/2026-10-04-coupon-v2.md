## 4. 影響範囲

- **ねじ → 壁 → キーの穴 → キャップ**: 下穴を変えても穴の位置は同じ。ナットにすると壁からはみ出して、キャップの胴に当たる
- **つまみの位置 → スイッチの足跡 → 電池の＋の線（VBAT_IN・VBAT_SW の右の端）・C_BAT・GND のビア → JLC の規約 → 監査**:
  (ii) にするなら、前に 1.75 動かしたときと同じ所を直して、監査し直す（決定記録 2026-10-04-switch-cover）
- **蓋 → 枠の口の上の壁の溝 → 右の枠**: 蓋 1・2 は溝を深くした枠が要る。基板には触れない

## 5. 試す物（v2）と、捨てた案

v2 の中身は docs/coupon-test.md 8 章の表。蓋の留め方で**捨てた案**:

| 案 | 捨てた理由（数） |
|---|---|
| v1 の腕のまま掛かりを 0.6 に | ひずみ 2.1 %（許容 1.0 %） |
| 長い腕 1 本（口の幅いっぱい・山は片側） | ひずみは 0.6 % で足りるが、山の無い側が留まらない: 蓋が山を軸に回って、反対の端が約 1.1 mm 開く（上の板の案内 4.35 と隙 0.15 × 2 から） |
| くさび（先細り）で擦り合わせる | 面一にならない: 刷る誤差 0.1 で、止まる深さが 0.6〜2.9 mm 変わる（傾き 10°〜2°） |
| 手前の面が垂直の山（引いても抜けない・押して外す） | 蓋を手前の面を下にして刷ると、垂直の面は宙に張り出す（0.75）。刷れない |
| 上の板の中の腕・枠の屋根の中の腕 | 上の板の下はクリップまで 0.2 しか無い（たわめない）。枠の側に付けると、傷むのが 4 時間かけて刷る枠になる |
| 横へ滑らせて掛ける | 口を蓋より 0.8 広くする = 手前の面に 0.8 の隙が見える |
| ナット・熱圧入インサート（ねじ） | 壁から 0.4 はみ出す。基板の変更になる（下穴の 3 通りが全部だめだったときの手） |

## この記録が乗っている前提

- 刷り方は 0.4 ノズル・層 0.1・Bambu PLA Basic（腕の太さ 0.7 = 線 2 本・0.45 = 線 1 本）
- ねじは M2×4 の小ねじ（タッピングではない）。掛かりの長さ 2.4
- 電源スイッチは MSK12C02・電池クリップは MY-1632-03-R
