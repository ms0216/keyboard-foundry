# 構造: 積み上げ・キャップと枠の形・刷る向き

- **日付:** 2026-10-03
- **状態:** 決定（方式と、試し刷りに出す形）。数値は `[暫定]`——試し刷りを触って確定する
- **決めた人:** 利用者（方式・A と B の両方を刷る・まず基板なしで試す）／形と数値の案は Claude

## 1. なぜ決める必要が生じたか

販売者は「工業用の 3D プリントでもバリで 10% くらい動作不良が出たので射出成形にした」と書いている（記事 acc-introduction）。
こちらは家庭用の FDM（A1 mini・0.4 ノズル・0.2 層・PLA）で刷るので、販売者の形をそのまま刷ると同じ所で失敗する。
基板は発注すると直せないので、**基板を設計する前に**、刷れる形と高さを決める。

## 2. 事実はどうか

**販売者の高さの読み**: 押す面 3.5 − ステム 3.4 = 浮き 0.1（公差で −0.1〜+0.3。ステムが高い個体は 0.1 押し込まれ、ON までの最小 0.1 を使い切る）。

0.1 垂れれば余裕が無くなる。**これが販売者の言う「バリで動作不良」の面。**

**スライサーの設定（A1 mini・0.20mm Standard を CLI で読んだ G-code の中の値）**: 象の足の補正 0・外周 2 本・Arachne・上 4 層・下 3 層。
1 層目の太りは形で逃がす必要がある。

## 4. 影響範囲（力と寸法の流れ）

指 → キャップの上面 → 胴（穴の壁に沿って動く）→ 下面（押す面）→ ステム。戻りはスイッチ → 下面。上の止まりは つばの上面 → くぼみの底 →
枠 → 柱 → 基板。

- つばの厚さ 0.4・くぼみ 1.0・枠の下面 3.0 → 押す面 3.6 → 浮き 0.2（0〜0.4）→ がた・押し始めの空走り → 感触（試し刷りの standin）
- 押す面 3.6 と浮きの最大 0.4 → 押し切りの沈み最大 1.0 → **公差の端ではキャップの上面が枠の上面と同じ高さまで沈む**（販売者は 0.9）
- くぼみ（深さ 1.0・穴の縁から 0.6）→ リブの中の壁 0.8 → 枠の強さ・くぼみの上の皮 0.6
- 柱（1.6 × 5.0・リブの中点）→ 基板の上の置けない場所 → ダイオード・595 の置き場（基板の段）
- 枠は上面を下に刷る → 上面はベッドの肌・穴の上の縁の面取りが 1 層目の太りを逃がす → 枠の反り（試し刷りの strip）
- キャップは下面を下に刷る → 上面は刷る向きの上（見た目）・9 個で 41 分（スライスの結果）なので 62 個で約 4.7 時間

## 5. 決めたこと

**積み上げ（基板の上面 = 0）**

| 面 | 高さ | 決め方 |
|---|---|---|
| スイッチの本体の上面 | 2.5 | 仕様書 |
| ステムの上面 | 3.4 ± 0.2 | 仕様書 |
| 枠の下面（= 柱の高さ） | 3.0 | 販売者と同じ。15 層 |
| 押す面（キャップの下面） | **3.6** | = ステムの最大。販売者 3.5 より 0.1 高い（押しっぱなしを無くす側） |
| 掛かる面（くぼみの底） | 4.0 | 枠の下面 ＋ くぼみ 1.0 |
| 枠の上面 | 5.0 | 販売者と同じ |
| キャップの上面 | 6.0 | 販売者と同じ。全体 8.1（底のシート 0.5 ＋ 基板 1.6 ＋ 6.0） |

**なぜ押す面を 3.6 にしたか（直せる側に倒す）**: 押しっぱなし（誤入力）は機能の失敗、浮き（がた）は感触の問題。キャップと枠は刷り直せるので
どちらも後から直せるが、基板が来て初めて分かる失敗（リフローでスイッチが浮く・個体差）は押しっぱなしの側にしか出ない。
層 0.2 の倍数で取れる押す面は 3.4 か 3.6 で、3.4 は公差の端で 0.2 押し込む。**3.6 が害の無い側。**浮きが気になるかは試し刷りで触る。

**キャップ（本番の形 F）**: 厚さ 2.4 の板（中は詰まっている）＋四隅の薄いつば（厚さ 0.4・穴の縁から 0.3 外へ・角から辺に沿って 3.0・
外の角は R1.0 で、穴の角 R2.25 の外に掛かりを作る）。
上の縁に面取り 0.8、下の縁に面取り 0.3。**下面をベッドに刷る。**
- 押す面 = 下面の全部 = ベッドの面（いちばん平らに出る）。φ3 の当て面を作らないので、当て面の高さの誤差が無い
- 掛かる面 = つばの上面 = 2 層目の上向きの面（宙に張り出さない・高さは層で決まる）
- 首が無い（販売者の「首と穴の角 0.11」という一番狭い隙が無くなる）
- 1 層目の太りは下の縁の面取りで穴・くぼみから離す

**枠**: 厚さ 2.0（3.0〜5.0）。穴の四隅の下面に、つばが入るくぼみ（深さ 1.0・つば ＋ 0.3。胴と穴の隙より広くして、横は胴で受ける）。穴の上の縁に面取り 0.4。
柱は 1.6 × 5.0 をリブの中点に。**上面をベッドに刷る**（くぼみの底・枠の下面・柱の先が上向きの面になる。支え無し）。

**平面**: A = 穴 16.5 × 16.0（販売者の 1u）、B = 穴 17.05 角（リブ 2.0）。どちらも 19.05 ピッチ・角 R2.25・キャップは穴より片側 0.20 小さい。
**A か B かは、試し刷りを触って利用者が決める。**

## 検討して捨てた案

| 案 | 捨てた理由 |
|---|---|
| 販売者の形のまま、上面を下に刷る（S） | 掛かる面が宙に張り出す（上の 2）。試し刷り latch の 5・6 番に入れて、実際にどれだけ垂れるかを見る |
| 掛かる面を 45° の斜面にする（C） | 垂れないが、掛かる高さが「首と穴の隙」で決まり、横の誤差 0.1 がそのまま高さ 0.1 になる。キャップが斜面で片側に寄る。試し刷り latch の 3・4 番で比べる |
| つばを「穴を一様に広げた形」にする | 穴を 0.1 広げた列で斜めにずれ切ると、角のつばの掛かりが 0.06 mm² まで減る（検査が落とした）。外の角を R1.0 にして角に掛かりを作った |
| 販売者の形を、足を下にして刷る | 押す当て面が宙に浮く（支えが要り、支えの跡が押す面に残る）。胴の下の縁も橋になる |
| 押す面 3.4（つば 0.6） | 公差の端で 0.2 押しっぱなし（検査が落とす）。試し刷り latch の 2 番で触る |
| くぼみを掘らず、枠の下面を 4.0 にする（枠を 1.0 薄く） | 枠の厚さが 1.0 になり、たわみで誤入力しやすい（販売者の記事「ケースの剛性が低いと誤動作」） |
| 中を空にして φ3 の当て面を立てる | 当て面の上が橋になる・幅の広いキーが柔らかくなる。板のままの方が硬くて刷りやすい（1u で 0.5 cm³ ≒ 0.62 g。スライスの結果） |

## この決定が乗っている前提（**動いたら読み直す**）

- スイッチが SKRAAWE010（ステムの上面 3.4 ± 0.2）。**SKRACAE010 は 3.5 ± 0.2 なので押す面を上げ直す**
- 刷る条件が 0.4 ノズル・0.2 層。層を変えると、機能する面の高さ（0.4・1.0・2.4）を取り直す
- 基板の上の、キャップの下に来る部品がスイッチの本体（2.5）より低い
- キャップを刷る（買わない）。販売者のキャップを買って使うなら、枠はくぼみ無し（下面 3.0 で掛ける）にする
