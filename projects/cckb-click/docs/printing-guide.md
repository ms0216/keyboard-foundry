# 刷り方（cckb-click の本番: 枠 2 枚・キャップ 62 個）

**結論: 先に「ねじの試し刷り」（約 28 分・基板を頼む前に要る）。本番は 4 枚のプレートで約 7 時間 48 分・PLA 約 73 g。
設定は試し刷りと同じ（0.4 ノズル・層 0.1・精度優先）。サポートもブリムも要らない。**
基板が無くても刷れる。刷ると open-gaps の #33・#10b・P1・P3・P5・P6 が分かる。

## 0. 先に刷る物: ねじの試し刷り（発注の門 #33）

| ファイル（build/cckb-click/） | 何 | 大きさ | 造形（準備込み） | 材料 |
|---|---|---|---|---|
| `coupon_screw_plate.stl` | 本番の枠から切り出した壁 2 つ ＋ 当て板 2 枚（M2×4 を締めて、割れないか・空回りしないかを見る） | 57.2 × 54.4 × 5.0 | 22m（28m） | 2.5 cm³・約 3 g |

することと結果の読み方は docs/coupon-test.md の「6. ねじの試し刷り」。**ねじ（M2×4 のスリムヘッド）が 4 本要る。**

    .venv/bin/python3 projects/cckb-click/tools/slice_main.py         # 4 枚をスライスして G-code を検査

| `frame_right.stl` | 右の枠（電池の口・電源スイッチの切り欠き） | 140.0 × 101.3 × 5.0 | 1h55m（2h01m） | 11.03 cm³・約 13.7 g | 49 |

## 2. 設定（試し刷りで利用者が確かめた物と同じ）

プリセットは `projects/cckb-click/print/cckb-click_precise_n04.json`。読み込み方は docs/coupon-test.md の「刷り方」と同じ
（ファイル → インポート → 設定をインポート → プロセスの一覧から `cckb-click precise 0.10 @A1M 0.4`）。

| 項目 | 値 |
|---|---|
| プリンタ・ノズル | A1 mini・0.4 |
| フィラメント | Bambu PLA Basic（乾かしてから） |
| プレート | Textured PEI・65℃ |
| 層の高さ／1 層目 | 0.1／0.2 |
| 線の幅（外周／1 層目） | 0.42／0.5 |
| 外周 | 3 本・内→外→内・Arachne |
| 外周の速さ・加速度 | 60 mm/s・2000 |
| 継ぎ目 | そろえる（Aligned）。形の側の溝（幅 2.0・深さ 0.5）に入る |
| 象の足の補正・X-Y 補正 | 0・0（試し刷りの 10 mm の塊がほぼ 10 mm だったので入れない） |
| 上・下の層／中 | 7・5／15% |
| ブリム・サポート・スカート | 無し |
| 刷る順 | 層ごと（全部一緒） |
| 置き方 | **回さない。**枠は上面が下（柱と壁が上を向く）。キャップは押す面が下 |
| 送る画面 | 「ベッドレベリング」と「流量ダイナミクスのキャリブレーション」を入れる |

なぜこの値かは決定記録 2026-10-03-print-recipe。スライスのたびに、この表のうち 25 個を G-code の設定の欄と突き合わせている（tools/slice_main.py）。

## 3. 刷ったら見る所

| 見る所 | 何を | だめなら |
|---|---|---|
| キャップ 62 個 | 枠の下から入れて、自分の重さで動くか。引っ掛かる物は縁のバリを爪で取る | その 1 個だけ刷り直す（`cap_*.stl`） |
| 枠の継ぎ目 | 左右を突き合わせて、継ぎ目の列のキャップが挟まらないか（P3） | `FRAME_SEAM_GAP` を広げて刷り直す |
| 柱の先・奥の壁のねじの所 | 継ぎ目の溝をまたぐ小さな橋（26 か所）が垂れていないか（P5）。垂れは基板に着く面に出る | やすりで平らにする |
| ねじの下穴 | M2 のねじを 1 本入れてみる（P1。**先にねじの試し刷りで見てある**はずの所）。外周 20 ＋ 手前の真ん中の予備 2 | きつい → φ1.7〜1.8 のドリル。空回り → `SCREW_PILOT_D` を 1.7 に |
| 枠の反り | 平らな所に置いて、角が浮かないか | ベッドの温度・置く向きを変えて刷り直す |
| 電池の口・指の切り欠き | CR1632 が口を通るか（基板が無くても電池だけで試せる） | `FINGER_NOTCH`・`CELL_SLOT_CLEAR` を広げて右の枠だけ刷り直す |

## 4. 回した検査／回していない検査

**回した**

- 形の検査（tests/test_cckb_click_case.py・33 件）: 1 マスの断面が試し刷りの枠と同じ・サポート無しで刷れる・左右とも A1 mini に置ける・
  置いたとき／押し切ったとき／傾けたときの干渉 0・キャップを下から入れられる・電池を出せる・USB を挿せる・ねじの周りの肉（22 か所を 10° おきに測る）・
  角の部品のパッドと枠の隙・ねじの試し刷りが本番の枠と同じ形。それぞれ故意に壊すと落ちる
- 4 枚とねじの試し刷りを Bambu Studio 2.8.2 のコマンドでスライス（警告 0・設定 25 個が G-code と一致）。ねじの試し刷りは OrcaSlicer でも

**回していない**

- Bambu Studio の**画面**からのスライス（確かめたのはコマンドから）
- OrcaSlicer での本番のスライス（試し刷りでは両方を回した。`tools/slice_main.py orca` で回せる）
- 0.2 ノズル（`tools/slice_main.py n02`）
- 継ぎ目が滑る面に出ていないかの数え直し（試し刷りの 1 マスでは 0。本番の 62 マスでは数えていない。形は同じ関数で作っている）
- 実物の寸法・反り・糸引き（刷らないと分からない）

**刷るかどうかは利用者の判断。**
