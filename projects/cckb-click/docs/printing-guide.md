# 刷り方（cckb-click の本番: 枠 2 枚・キャップ 62 個・電池の蓋）

**結論: 本番は 5 枚のプレート（枠 2・キャップ 2・電池の蓋）で約 7 時間 55 分・PLA 約 73 g。設定は試し刷りと同じ（0.4 ノズル・層 0.1・精度優先）。サポートもブリムも要らない。
電池の蓋は、道具なしで上から落とし込む形に変えた（2026-10-04）。先に、蓋の試し刷り（約 40 分・蓋 3 つ・下の 0 章）を刷って、留まるか・外れないか・開けられるかを見る。**
基板が無くても刷れる。刷ると open-gaps の #10b・P1・P3・P5・P6 が分かる。

**2026-10-04 に形が変わった**（利用者が試し刷り v2 を刷って決めた。決定記録 2026-10-04-knob-out-pilot）: ねじの下穴 φ1.8 → **φ1.6**（22 個とも）・
電源スイッチのつまみの切り欠きが、**0.75 外へ寄った位置で、外へ広がる形**（利用者が (ii) で触った形）。**前に刷った枠があれば、右も左も刷り直す**（下穴が違う）。
**同じ日にもう 1 つ変わった**（決定記録 2026-10-04-cover-latch）: **右の枠の電池の口**が、幅 19.0 で上から下まで抜いた溝・左右に三角の溝（蓋の耳が入る）・手前の左右の角に小さな歯（蓋の棒の先が下に入る）になった。左の枠は変わらない。

## 3. 刷ったら見る所

| 見る所 | 何を | だめなら |
|---|---|---|
| キャップ 62 個 | 枠の下から入れて、自分の重さで動くか。引っ掛かる物は縁のバリを爪で取る | その 1 個だけ刷り直す（`cap_*.stl`） |
| 枠の継ぎ目 | 左右を突き合わせて、継ぎ目の列のキャップが挟まらないか（P3） | `FRAME_SEAM_GAP` を広げて刷り直す |
| 柱の先・奥の壁のねじの所 | 継ぎ目の溝をまたぐ小さな橋（26 か所）が垂れていないか（P5）。垂れは基板に着く面に出る | やすりで平らにする |
| ねじの下穴（φ1.6） | M2 のねじを 1 本入れてみる（P1。径は試し刷り v2 で利用者が決めた）。外周 20 ＋ 手前の真ん中の予備 2。**5 回締め直して、止まる手応えが残るか**（回数はまだ分かっていない） | きつくて入れ始められない → φ1.6〜1.7 のドリルを手で通す。空回り → Claude に言う（v2 では空回りしなかった径） |
| 枠の反り | 平らな所に置いて、角が浮かないか | ベッドの温度・置く向きを変えて刷り直す |
| 電池の口 | CR1632 が口を通るか（基板が無くても電池だけで試せる。口の幅は 19.0・手前の角の歯の間は 17.0）・**歯が欠けていないか** | 口の奥行き `FINGER_NOTCH_DEPTH`・歯の出 `COVER_TOOTH` を直して右の枠と蓋を刷り直す |
| 電池の蓋 | 棒 2 本が、まわりから離れているか（切れ目が埋まっていないか）・押し下げるだけで留まるか・上へこじって抜けないか（蓋の試し刷りで先に見る: docs/coupon-test.md 10 章） | 試し刷りで選んだ組に `COVER_MAIN` を合わせて、蓋だけ刷り直す（約 11 分） |
| 電源スイッチの切り欠き（右の壁） | 外へ広がった角が欠けていないか・内側の斜めの面が垂れていないか・切り欠きの中に糸が残っていないか。**内側の縁（斜面の下の、厚さ 1.2 の所）を指で強く押さない**（厳しい見方で、10 N で上限の半分強・20 N で上限を超える見積もり） | 糸はピンセットで取る。割れたら Claude に言う（斜めに落とす量を減らす） |

## 4. 回した検査／回していない検査

**回した**

- 形の検査（tests/test_cckb_click_case.py）: 1 マスの断面が試し刷りの枠と同じ・サポート無しで刷れる・左右とも A1 mini に置ける・
  置いたとき／押し切ったとき／傾けたときの干渉 0・キャップを下から入れられる・電池を出せる・USB を挿せる・ねじの周りの肉（22 か所を 10° おきに測る）・
  角の部品のパッドと枠の隙・ねじの試し刷りと角の試し刷りが本番の枠と同じ形・電源スイッチのつまみの先が基板の縁の 0.30 内／枠の外面の 0.60 内で、
  爪の入る場所が空いている・指先の代わりの球がつまみの先より奥へ入る・切り欠きの内側の縁の強さ（断面を立体から測る）・下穴が 22 個とも φ1.6。
  **電池の蓋**（落とし込み式）: 枠・電池・クリップ（図面から作った形）・基板・部品・キャップに当たらない・面一・電池は手前へ 0.35 で蓋の足に止まる・
  蓋を付けると電池は 10 の向きのどれにも出ない・蓋は棒を 0.95 押し込まないと上へ抜けない・回しても出ない・手前の面をベッドにサポート無し。それぞれ故意に壊すと落ちる
- **本番の 4 枚を Bambu Studio 2.8.2 のコマンドでスライス**（2026-10-05・電池の口を落とし込み式の蓋の形に変えた後にもう一度。警告 0・設定 25 個が G-code と一致・**下穴 22 個の径を G-code で測った**: 上の表。
  測り方は、穴の中心を 0.1 ずらす・φ1.5 の幅で見る、で NG になることを見た）
- **蓋と、蓋の試し刷りを同じコマンドでスライス**（`tools/slice_cover.py`。警告 0・設定 25 個が一致・蓋の切れ目 3 本に線が通っていない・棒の所に線がある・棒の厚さより上に棒が無い。見る点を 0.6 ずらすと NG になることを、回すたびに見ている。絵 slice_cover.png）

- Bambu Studio の**画面**からのスライス（確かめたのはコマンドから）

- **本番の枠に、実際にねじを入れていない**（径は試し刷りの切れ端で確かめた物と同じ、まで）
- 0.2 ノズル（`tools/slice_main.py n02`）
