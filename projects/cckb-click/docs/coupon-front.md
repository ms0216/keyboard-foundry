# 手前の縁を細くする試し刷り（coupon_front）

**これは試し刷りだけ。本番の枠（click_case.py）・基板・spec.py は変えていない。**結果を見てから、基板を変えるかを決める。

絵を先に見る（`build/cckb-click/`）: `coupon_front_howto.png`（刷る物・組み方・手で見る所）・`coupon_front_sections.png`（断面と数）。

## 何を確かめるか

いまの枠は、外周の壁に下からねじを立てるので、縁が四方とも 3.0 ある（キャップから外面まで 4.2）。手前はトラックボールが来るので、できるだけ細くしたい。
検討（`build/cckb-click/study/front_wall_*.png`）では、ねじを残すかぎり 2.6 が限度で、効くのは次の形（案 B）だけだった。

- キーの手前の壁のねじをやめる
- 枠の手前の壁を、基板の手前の縁の外へ下ろし、先の小さな出っ張り（爪）を基板の下へ回す
- 基板は、手前の縁を爪に引っ掛けてから倒し、奥と左右をねじで留める（基板の手前の縁を 2.85 か 3.25 引っ込める）

爪は 0.8 の壁の先に付く 0.6 の出っ張りで、**刷れるか・基板を保てるかは計算では決められない**（この機種では、計算で成り立った留め方が 4 回、刷ると使えなかった）。
基板は発注すると直せないので、先にこれだけ刷る。

枠の切れ端は、本番の枠の手前の段の 左 Alt（1u）・左 Meta（1.5u）・左の Space（2.25u）の所（幅 92.5）。穴・くぼみ・面取り・柱は本番の立体から切り出した。

**本番と違う所**（試し刷りのために作った所）:

- 手前: 上の板を外面まで・基板の縁の外を下りる壁（厚さ 0.8）・爪。キーの辺の真ん中に、本番のねじの所と同じ形の厚い壁（基板に載る所。下穴は無い）。
  Meta の所の厚い壁は、本番には無い
- 奥: 本番の外周の壁と同じ断面の壁（下穴 φ1.6・深さ 2.8・外面から 2.4）を、すぐ奥のリブの所に付けた。**本番で手前にいちばん近いねじは、ここまで近くない**
  （奥の壁は 95 mm 先・左右の角のねじは爪の両端）。この試し刷りは、本番より手前が浮きにくい
- 縁 0.4 の枠は、奥の下穴を 0.4 奥へ寄せてある（同じ板を 2 つの枠で使うため）。スイッチの代わりは、どちらの枠でもキーの中心から 0.2 ずれる
- 基板の代わりの厚さは、層の倍数の 1.4・1.6・1.8（基板の公差 1.44〜1.76 を外から挟む）

## 爪の形と、その理由

枠は上面をベッドに刷る。**爪は刷る向きのいちばん上に出来て、掛かる面は宙へ張り出す。**

- 掛かる面を水平にすると、0.6 の張り出しを支え無しで刷ることになる → **水平から 30° の斜面**にした（層 0.1 で 1 層に 0.17 = 線の幅の 41 % ずつ出る）
- 斜面なので、基板の縁の位置（前後）のずれが、そのまま浮き（上下）に変わる（ずれ × 0.58）
- 爪の下面は基板の下面（名目）から 0.6 下 = **底のシート 0.5 の下面より 0.1 下へ出る**（ねじの頭の最大と同じ高さ）。シート 0.5 では隠れない
- 壁は 0.8 の板が 92 mm 続く形なので、ばねのようには逃げない。**爪は撓んで入るのではなく、基板を斜めに差すか、奥へ 0.5 ずらして入れる。**
  留めているのは奥のねじ（基板が奥へずれなければ外れない）

爪（2 つの枠で同じ）:

| | 名目 | 基板の厚さ 1.44〜1.76 と刷りの誤差 ±0.15 | 基板の外形 ±0.2 も足すと |
|---|---|---|---|
| 爪が基板の下へ入っている量 | 0.45 | 0.30〜0.60 | 0.10〜（隙が −0.20 = 壁に当たる） |

入れる動き: 10° 倒して差すなら、奥へ 0.15（B2）〜0.25（B3）引いた所から。倒さずに平らに置いて、手前へ 0.5 ずらしても入る。

## 組み方・手で見る所・報告してほしいこと

`coupon_front_howto.png` に同じことが絵つきで書いてある。

1. 枠を裏返して机に置く。キャップ 3 個を、つばを上にして穴に落とす
2. 基板の代わり B2 を、スイッチの代わりを下に向けて、ねじ穴の無い縁を爪の側へ向ける
3. その縁を爪の下へ斜めに差し込み、押し込みながら倒す
4. 奥のねじ穴 3 つに M2×4 を締める
5. 表に返して、キャップを押す

手で見る所（F08 と F04 のそれぞれ）:

- ア. 爪が刷れているか（垂れ・糸・欠け）
- イ. 基板の代わりが入るか・外せるか（B1・B2・B3）
- ウ. ねじを締めて、手前の縁に爪を掛けて持ち上げる。浮く量・爪が外れるか・壁が割れるか
- エ. 手前の縁を奥へ押しながら Space のキャップを押す。引っ掛かるか
- オ. 手前の縁の触り心地。どちらの縁がよいか
- カ. 机に置いて、手前の爪が机に当たってがたつくか

## 確かめたこと・確かめていないこと

**回した検査**（`tests/test_cckb_click_front_coupon.py` 16 件。壊して落ちることも見ている）:

- 穴の手前の縁から奥は、本番の枠と同じ立体
- 縁の数（立体に点を打って測る）・くぼみの外の皮
- キャップ 3 個を、掛かった位置・押し切り・四方へ傾けた姿で枠に重ねて、当たらない
- 爪の掛かり 0.45・公差の端の数・持ち上げたときに当たるまでの量（立体を動かして測り、式と合う）。爪の無い枠では止まらない
- 基板の代わり 3 枚 × 枠 2 つ × 角度 0°・10°・20° で、差してから倒す道の各段（1° ごと）で立体が当たらない。外すのは同じ道の逆。
  スイッチの代わりとキャップも当たらない。手前の縁が 0.3 長い板・厚さ 2.4 の板は入らない
- ねじを外して奥へ 0.5 引けば、爪は掛からない（= 外せる・留めているのは奥のねじ）
- 基板の上面より下へ出るのは、手前の壁と爪だけ。爪の下面は −2.2
- 奥の下穴のまわりの肉が本番の奥の壁と同じ・板の穴が下穴の真上
- 刷る向きで宙へ張り出す面は、爪の斜面と、奥の厚い壁が継ぎ目の溝をまたぐ所 3 つ（本番の奥の壁と同じ）だけ
- スライスした G-code（Bambu Studio）: 設定 25 個・支えの線なし・壁は線 2 本で幅 0.80・爪のいちばん上の層は線 3 本で幅 1.40・
  くぼみの外の皮は 3 本 1.20 / 2 本 0.80・爪の斜面は 8 層で 0.60 出て 1 層の最大 0.178・下穴 6 個は φ1.54

スライサーの出力で除外した物: `ZFiller: encounter idx from clip` が 3 件（Bambu Studio が [error] で出す）。部品を分けてスライスして、
縁 0.4 の枠の奥の下穴 3 つ（壁の中に閉じた止まり穴）から出ていて、爪とは関係が無いことを確かめた。穴の底の層の線は縁 0.8 の枠と同じに出ている。
4 件以上なら `tools/slice_front.py` は NG にする。

**確かめていないこと**（刷って見る・あるいは別に調べる）:

- **爪が実際に刷れるか・持つか**（これが、この試し刷りの目的）。層の間の強さは計算していない
- 本番の長さ（爪は約 210 mm・留めは両端の角と奥の壁）での浮き。試し刷りは奥のねじが 20 mm の所にあり、本番より有利
- 本番の基板を斜めに差す動きが、左右の角（XIAO・電池クリップ・電源スイッチが枠の逃げの中に入る。横の隙 0.4）で出来るか。
  差すには、基板を奥へ 0.15〜0.5 ずらす必要がある
- 基板の外形の公差 ±0.2 の影響（刷った板の縁は基板の縁ではない）。式では、隙 0.15 を使い切って壁に当たる側がある
- 底のシートの厚さ（爪はシート 0.5 より 0.1 下へ出る。足を付けるなら問題にならない）
- 行の線（銅）と基板の縁の距離・無くなるねじ 7 本のあとの固さ（基板の側の検討。ここでは見ていない）
- 0.2 ノズルの刷り方（n04 だけ切った）

## 作り直すとき

```
.venv/bin/python3 projects/cckb-click/click_coupon_front.py        # STL と絵
.venv/bin/python3 projects/cckb-click/tools/slice_front.py         # スライスと G-code の検査 → coupon_front_plate_n04.gcode.3mf
.venv/bin/pytest tests/test_cckb_click_front_coupon.py -q          # 約 1 分半
```

寸法は `click_coupon_front.py` の冒頭の定数（試し刷りだけの値）。本番に入れると決めたら spec.py へ移す。
