- **「片方だけでは開かない」は、案内の隙 0.10 の蓋 1 でしか言えない。**0.25 の蓋 3 は、片方ずつ 2 回に分ければ開く（わざとでないと起きない動きなので、

## 刷り方

  （枠の角・当て板・電池の代わり・蓋 3 つ）。刷り方の設定は、精度優先のまま変えていない
- **当て板は、提案どおりに変えた基板の形**（クリップの脚と止めが 2.0 奥・H15 が 140.0・H30 と H31 なし）。いまの本番の試し刷りの当て板とは合わない
- **枠の角には、クリップの板の代わりが付いている**（試し刷りだけ。屋根を、板の範囲で、下面の高さ 3.5 まで厚くした）
- 蓋の見分け: 上の板の奥の縁の切り欠きの数 = **奥の案内の隙**: 蓋 1 = 0.10・蓋 2 = 0.15・蓋 3 = 0.25（上の「蓋 3 つ」）。腕・予圧・かぎは 3 つとも同じ
- **きつくて、爪だけで引き抜けない蓋は、その隙が不合格。こじらない**（本番では、電池を裏から押せない）
- 回した検査: 立体の検査 18 件・スライスと G-code の検査（設定 25 個・警告 0・支えの線なし・見る点をずらすと落ちる）。

## 刷らないと分からないこと

| 項目 | 理由 |
|---|---|
| a〜l（`coupon_cover_snap_howto.png`） | 前の 4 つの差し込み式は、計算が 4 回とも「留まる」と言って外れた |
| **どの案内の隙なら、噛まずに入り、爪だけで抜けるか** | 蓋を動かす力が、噛んだときの摩擦より 1 桁小さい。蓋 3 つで見る |
| 蓋 1 で、手を離すと本当に戻るか（片方だけ）・押し切る手前で引き込まれるか | 斜め 0.35 と出る量 0.26 の差 0.09 は、刷りの誤差と同じ桁 |
| 爪が、つまみの段に掛かるか・段（0.4 × 0.4）が欠けないか | 手でしか分からない |
| **本物のクリップで、電池を爪で出せるか** | 舌の固さの値が無い。試し刷りでは再現できない。基板とクリップが届いてから |
| 座りの固さ（0.2〜0.4 N）が、手で触って足りるか・へたって抜けないか | PLA のクリープは計算していない |
| 腕・柱が、何 N で白くなるか | 38 N は TDS の値での計算 |
| 本物のクリップ・電池での固さ | 当て板にクリップの板と舌の代わりは無い |
