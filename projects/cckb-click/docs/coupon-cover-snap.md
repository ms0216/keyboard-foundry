**B の弱い所は、基板を 3 か所変える前提で、形を足さずに（寸法と位置で）直せた。**

**直せなかった所・新しく弱くなった所（正直な所）**

- 座りの力は 1 N に届かない。腕の力は「外すときのひずみの上限」で頭が決まる（腕 1 本が出せる力は、外す所でも 1.2 N）。0.2〜0.4 N は、蓋が自分の重さで鳴らない力であって、指で押せば 0.15 引っ込む

- Shift・Fn の穴のくぼみと、クリップの上の薄い屋根の間に残る厚い屋根が 4.1 → 2.1 になる（基板の提案 ① の代償）
- 力の仮定（20 N）と強さ（TDS）は、どちらも測った値ではない

## 刷り方

- `coupon_cover_snap_plate_n04.gcode.3mf`: A1 mini・0.4 ノズル・層 0.1・PLA・支え無し。**造形 45 分 36 秒（準備込み 52 分 4 秒）・5.85 cm3・7.38 g**・6 個
  （枠の角・当て板・電池の代わり・蓋 3 つ）。刷り方の設定は、精度優先のまま変えていない
- **当て板は、提案どおりに変えた基板の形**（クリップの脚と止めが 2.0 奥・H15 が 140.0・H30 と H31 なし）。いまの本番の試し刷りの当て板とは合わない
- 蓋の見分け: 上の板の奥の縁の切り欠きの数。まだ分からないのは「腕の固さと予圧」なので、そこを振った:
  **蓋 1** = 腕 0.85・予圧 0.30（やわらかい）/ **蓋 2** = 腕 0.90・予圧 0.30（本番の候補）/ **蓋 3** = 腕 0.95・予圧 0.20（固い・座りは弱め）。
  かぎの形と、嵌めの隙は 3 つとも同じ
- 回した検査: 立体の検査 16 件・スライスと G-code の検査（設定 25 個・警告 0・支えの線なし・見る点をずらすと落ちる）。
  **回していない検査: 刷った物での全部**

## 刷らないと分からないこと

| 項目 | 理由 |
|---|---|
| a〜l（`coupon_cover_snap_howto.png`） | 前の 4 つの差し込み式は、計算が 4 回とも「留まる」と言って外れた |
| 奥の案内の隙 0.10 で入るか | きつい側に倒した。入らなければ削る |
| 手を離すと本当に戻るか（片方だけ）・押し切る手前で引き込まれるか | 斜め 0.35 と出る量 0.26 の差 0.09 は、刷りの誤差と同じ桁 |
| 座りの固さ（0.2〜0.4 N）が、手で触って足りるか・へたって抜けないか | PLA のクリープは計算していない |
| 爪で左右をつまめるか | 手でしか分からない |
| 腕・柱が、何 N で白くなるか | 38 N は TDS の値での計算 |
| 本物のクリップ・電池での固さ | 当て板にクリップの板と舌の代わりは無い |

## どれを刷るか

利用者が B を土台に選んだので、**B2 を刷る**。A の試し刷り（`coupon_corner_plate_n04.gcode.3mf`）は基板を変えずに済む形なので、B2 が駄目だったとき・基板を変えたくないときの比べる相手として残す。
