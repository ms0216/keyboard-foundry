## 刷り方

- `coupon_cover_snap_plate_n04.gcode.3mf`: A1 mini・0.4 ノズル・層 0.1・PLA・支え無し・縁取り無し。**造形 54 分 57 秒（準備込み 1 時間 1 分 26 秒）・5.90 cm3・7.43 g**・6 個
  （枠の角・当て板・電池の代わり・蓋 3 つ）。刷り方の設定は、精度優先のまま変えていない
- **当て板は、提案どおりに変えた基板の形**（クリップの脚と止めが 2.0 奥・H15 が 140.0・H30 と H31 なし）。いまの本番の試し刷りの当て板とは合わない
- **枠の角には、クリップの板の代わりが付いている**（試し刷りだけ。屋根を、板の範囲で、下面の高さ 3.5 まで厚くした）
- **刷り方を 4 つ変えてある**: 1 層目の速さ（`initial_layer_speed` 50 → 20・`initial_layer_infill_speed` 105 → 30 mm/s）と、2 層目から上の内の壁・詰まった中の速さ（`inner_wall_speed` 150 → 80・`internal_solid_infill_speed` 180 → 100 mm/s。細い腕の上を速く走らない。層ごとに変える設定は、この設定の組に無い）。Bambu Studio で STL から切り直すときは、この 4 つを入れること
- 蓋は、板の真ん中の 3 列（ベッドの中心から前後 25 mm 以内）。**刷る前に、ベッドの板を洗う**
- 蓋の見分け: 上の板の奥の縁の切り欠きの数 = **きつさ**（上の「蓋 3 つ」）
- **使う前に、腕の付け根と柱の間の隙が底まで開いているかを見る**（膜で付いていたら、薄い刃で切り離す）。開け閉めのたびに、腕の付け根が白くなっていないかを見る
- つまんでも出てこなければ、B4 と同じに、つまんだまま手で引く。**出てこないときに見てほしい 4 つ**は、手順の絵（d）に書いてある
- 回した検査: 立体の検査 20 件・スライスと G-code の検査（設定 29 個・警告 0・支えの線なし・見る点をずらすと落ちる）。
  **回していない検査: 刷った物での全部**

## 刷らないと分からないこと

| 項目 | 理由 |
|---|---|
| a〜l（`coupon_cover_snap_howto.png`） | 前の 4 つの差し込み式は、計算が 4 回とも「留まる」と言って外れた |
| **つまむだけで、本当に蓋が出てくるか** | B4 は、計算が「出る」と言って出なかった。B5 は計算を直したが、かぎが外れてから押し始めるまでの余裕 0.06 は、刷りの誤差より小さい（かぎの角の斜め 0.3 が、その分を逃がす作りではある）。腕は、計算より柔らかく・固く刷れる |
| **どのきつさが良いか・まだ遊ぶ向き** | がたは、手でしか分からない。前後 0.15 と上下 0.2 は、今回は詰めていない |
| 指の腹で、上面を滑らせて動かせるか（幅 2.85 × 奥行き 2.6） | 手でしか分からない |
| 横向きに落として、蓋が外れないか | つまみが重くなり、計算の余裕が無い（1500 G は借りた仮定） |
| ベッドから剥がれないか | 面積は 5 % しか増えていない。1 層目の速さと、板の真ん中・板を洗う、が効くかは刷って見る |
| 鞄の中で、上面のつまみが両方同時に内へ押されることが起きるか | つまみは、上面から指で動かせるようになった。両方を 1.6 ずつ内へ、が要る |
| **本物のクリップで、電池を爪で出せるか** | 舌の固さの値が無い。試し刷りでは再現できない。基板とクリップが届いてから |
| 座りの固さ（0.2〜0.4 N）が、手で触って足りるか・へたって抜けないか | PLA のクリープは計算していない |
| 腕・柱が、何 N で白くなるか | 38 N は TDS の値での計算 |
| 本物のクリップ・電池での固さ | 当て板にクリップの板と舌の代わりは無い |

## どれを刷るか

利用者が B を土台に選んだので、**B5 を刷る**（B4 は、手で引けば抜ける所まで確かめ済み）。A の試し刷り（`coupon_corner_plate_n04.gcode.3mf`）は基板を変えずに済む形なので、B5 が駄目だったとき・基板を変えたくないときの比べる相手として残す。
