# 試し刷り（cckb-click・基板なし）

**最初に刷るのは 1 枚だけ。**約 45 分。刷ったら、測って、組んで、3 つの穴のどれが合うかを見る。

絵を先に見る（build/cckb-click/）: `min_set.png`（置く向き・組んだ所・断面）、`slice_n04.png`（スライスした線）。

## 1. 何を刷るか

| | |
|---|---|
| ファイル | `build/cckb-click/coupon_min_plate.stl`（3 つの部品を 1 枚に並べた物） |
| 中身 | キャップ 3 個（同じ形）＋ 測る塊 1 個 ／ 枠 1 個（穴 3 つ ＋ 測る穴）／ 板 1 個 |
| 時間・材料 | 0.4 ノズル: 造形 43 分（準備込み 50 分）・7.3 cm³（約 9 g）。0.2 ノズル: 造形 1 時間 35 分（準備込み 1 時間 43 分）・6.7 cm³ |

部品を 1 個ずつ刷り直したいときは `coupon_min_caps.stl`・`coupon_min_frame.stl`・`coupon_min_base.stl`（中身は同じ）。

## 2. どう刷るか

| | |
|---|---|
| プリンタ | **A1 mini** |
| ノズル | **0.4**（いま付いている物でよい）。0.2 を持っていれば 0.2 の方が細かく出る（下の「ノズル」） |
| フィラメント | Bambu PLA Basic。色は何でもよい。**乾いた物**（湿っていると糸を引き、それがバリになる） |
| プレート | Textured PEI（ざらざらの金色の板）。別の板なら、スライサーで板の種類を選び直す |
| 設定 | `projects/cckb-click/print/cckb-click_precise_n04.json`（名前 `cckb-click precise 0.10 @A1M 0.4`）。0.2 ノズルは `cckb-click_precise_n02.json`（名前 `cckb-click precise 0.10 @A1M 0.2`） |
| 向き | **回さない。**読み込んだままの向きで刷る。キャップは押す面（下面）が下。枠は上面が下（柱が上を向く）。板は下面が下 |
| サポート・ブリム | **どちらも無し**（設定に入っている。ブリムは縁にバリを残す） |
| 印刷を送るとき | 「ベッドレベリング」と「流量ダイナミクスのキャリブレーション（Flow Dynamics Calibration）」に**チェックを入れる** |

**手順（Bambu Studio）**

1. プリンタを「Bambu Lab A1 mini 0.4 nozzle」、フィラメントを「Bambu PLA Basic」にする。
2. ファイル → インポート → 設定をインポート で `cckb-click_precise_n04.json` を読む。プロセスの一覧から `cckb-click precise 0.10 @A1M 0.4` を選ぶ。
3. `coupon_min_plate.stl` を読み込む。「複数の部品に分けますか」と聞かれたら「いいえ」。回さない。
4. スライスする。プレビューで**継ぎ目（白い点）が、キャップと穴の小さな溝の中に並んでいる**のを見る。角に並んでいたら刷らずに知らせる。
5. 印刷する。

**近道**: `build/cckb-click/coupon_min_plate_n04.gcode.3mf` は、この設定で Bambu Studio 2.8.2 が切った物（検査したのはこの G-code）。
Bambu Studio で開いてそのまま送れるはず。ただし**画面で開く所は確かめていない**。開けなければ上の手順で。

設定が読み込めなかったら、`0.12mm High Quality @BBL A1M` を選び、次の 9 つを手で変える:
層の高さ 0.1 ／ 外周の数 3 ／ 外周の順 内→外→内（Inner/Outer/Inner）／ 壁の作り方 Arachne ／ 上の層 7・下の層 5 ／ 継ぎ目 そろえる（Aligned）／
壁をまたがない移動（Avoid crossing walls）入 ／ ブリム 無し ／ 象の足の補正 0。

## 3. 刷ったあとにすること

1. 板が冷めてから外す（熱いうちに曲げると反る）。
2. **バリを取らない。**そのまま見る。キャップの下の縁・四隅のつば・奥の小さな溝。糸やこぶがあれば、どこにあるかを書く。
3. **測る**（ノギス）。下の「測る表」に書く。
4. **組む。**
   1. 枠を裏返して机に置く（柱が上）。
   2. キャップを**上面を下にして**穴に落とす。キャップの溝と、穴の溝を同じ側にする。3 個とも同じ形なので、どの穴に入れてもよい。
   3. 板を裏返してかぶせる。落とした角どうしを合わせる。
   4. 全体を押さえたまま表に返す。
5. **試す。**穴の番号は、枠の手前の縁の点の数（1・2・3）。右へ行くほど穴が 0.1 ずつ広い。
   - 組んだ物を**逆さにして、また戻す**。キャップが自分の重さで上下に動くか（カタッと音がする）。
   - キャップを指で横に揺する。がたの量。
   - 逆さにして振る。キャップが落ちてこないか。
   - 外して、枠の穴の壁とキャップの横の面をなでる。引っ掛かる所があるか。

## 4. 何を見るか・結果の意味

| 見るもの | こうなら | 意味 |
|---|---|---|
| 逆さにして戻すと、キャップが自分の重さで動く | 3 つとも動く | **この方式は刷れる。**いちばん狭い穴（1 番）でよい |
| | 2 番・3 番だけ動く | 隙を広げる（`CAP_CLEAR` を 0.25 か 0.30 に） |
| | どれも動かない | 測る表を見る。外寸が大きい・内寸が小さいなら、スライサーの補正を入れて刷り直す（下） |
| 指で軽く押すと動くが、自分の重さでは動かない | | 際どい。スイッチが戻す力は約 10 g、キャップは約 0.6 g。使えるかもしれないが、1 つ広い穴を選ぶ |
| 横のがた | 3 番が大きすぎる | 狭い方を選ぶ。1 番でも大きいなら隙を詰められる |
| 逆さにして振ると落ちる | | つばの掛かりが足りない（`TAB_REACH`）。知らせる |
| 継ぎ目のこぶ | 溝の中にある | 狙いどおり |
| | 角や平らな面にある | 設定が効いていない。スライサーの画面を見直す |
| キャップの上面 | 筋が気になる | アイロンがけを足す（今回は入れていない） |
| キャップの奥の縁の切れ込み（幅 2.0） | 見た目が許せない | 知らせる。溝を上まで通さない形に変える |

### 測る表

測る塊は、キャップの列の右にある四角（10 角・高さ 3）。右に薄い段がついている。**段のある向きが X。**

| 測る所 | 設計 | 測った値 |
|---|---|---|
| 塊の幅 X（段より上をはさむ） | 10.00 | |
| 塊の幅 Y | 10.00 | |
| 塊の高さ | 3.00 | |
| 塊の段の厚さ | 0.40 | |
| 枠の測る穴 X（内寸） | 10.00 | |
| 枠の測る穴 Y（内寸） | 10.00 | |
| キャップの厚さ（3 個） | 2.40 | |
| キャップのつばの厚さ（3 個。段と同じ厚さのはず） | 0.40 | |
| キャップの胴の幅 X（つばの無い真ん中をはさむ） | 16.65 | |
| 穴の幅 X（1 番・2 番・3 番） | 17.05・17.15・17.25 | |

**ずれたらどこへ戻すか**

| ずれ方 | 戻す所 |
|---|---|
| 外寸が大きく、内寸が同じだけ小さい（例: 10.10 と 9.90） | 線が太い。プリセットの「X-Y 外形補正」を −（ずれの半分）、「X-Y 穴補正」を +（ずれの半分）にする（例: −0.05 と +0.05）。0.1 を超えるなら先にフィラメントの流量のキャリブレーションをやり直す |
| X だけ、または Y だけがずれる | 機械の側（ベルト）。設定では直さない。知らせる |
| 高さ 3.00 は合うが、段とつばの 0.40 がずれる | 1 層目のつぶれ方。0.05 以内ならそのまま。超えたら知らせる（浮きがその分だけ変わる） |
| 高さ 3.00 もずれる | 層の厚さの問題。知らせる |
| 寸法は合うのに擦れる | 面の粗さかバリ。どこが当たっているかを書く |
| 寸法が合い、1 番で動く | `CAP_CLEAR` 0.20 のまま進む |

## ノズル（0.4 と 0.2）

| | 0.4 ノズル | 0.2 ノズル |
|---|---|---|
| 線の幅 | 0.42 | 0.22 |
| 1 層目の厚さ | 0.2 | 0.1 |
| 角の丸まり・継ぎ目のこぶ・糸 | ふつう | 小さい（線が半分の幅） |
| 最小の一式の時間 | 43 分 | 1 時間 35 分 |
| キャップ 62 個の時間（1u 9 個のスライスから比で出した見積もり） | 約 3 時間（9 個で 27 分） | 約 6.6 時間（9 個で 58 分） |
| 使えないフィラメント | — | ラメ・木・石・金属・カーボン入り・TPU（詰まる） |

**まず 0.4 で刷る。**3 つの穴のどれかで自分の重さで動けば、0.4 のままでよい。動かない・バリが出るなら 0.2 を試す。
この Mac の Bambu Studio には、0.2 ノズルで PLA Basic の流量を合わせた記録が残っている。**0.2 ノズルを持っているかは利用者に確認**（open-gaps #21）。

### 1. b（と a）: 大きさ・間隔と、穴の広げ方

`coupon_b_frame` ＋ `coupon_ab_base` ＋ `coupon_b_caps`。a は `coupon_a_frame` ＋ 同じ板 ＋ `coupon_a_caps`。

列（枠の手前と奥の縁の点 1・2・3）で穴が 0.1 ずつ広い（片側の隙 0.20 / 0.25 / 0.30）。台は全部 3.4（浮き 0.2）。

| すること | 見るもの | 決まること |
|---|---|---|
| キャップを入れる | 下から抵抗なく入るか。引っ掛かる列はどれか | 穴の広げ方（`CAP_CLEAR`） |
| 表に返して 1 個ずつ軽く押し、離す | **自分の重さで落ちて、指を離すと元の高さに戻るか**（スイッチは 0.1 N ≒ 10 g でしか戻さない。擦れる列は使えない） | 同上 |
| 裏返して振る | 落ちてこないか。つばが掛かっているか | つばの出（`TAB_REACH`） |
| 指で横・斜めに揺する | がたの量。隣と当たらないか | 穴の広げ方 |
| 9 個を並べて打つまねをする | キーの大きさと間隔（a は隙が広い・b は詰まっている） | **案 A か B か**（利用者の好み） |
| 上面を見る・なでる | 積層の跡が気になるか。面取りの大きさ | 上面の仕上げ（open-gaps #13） |

| 番号 | 台の高さ | 実物でいうと | 浮き |
|---|---|---|---|
| 1 | 3.2 | ステムが公差でいちばん低い | 0.4 |
| 2 | 3.3 | | 0.3 |
| 3 | 3.4 | **名目** | 0.2 |
| 4 | 3.5 | SKRACAE010 の名目 | 0.1 |
| 5 | 3.6 | ステムがいちばん高い | 0 |
| 6 | 3.7 | 範囲の外（SKRACAE010 のいちばん高い）。**押し込み 0.1** | −0.1（枠が浮く） |

| すること | 見るもの | 決まること |
|---|---|---|
| 各キーを指で上下に動かす・振る | がたの量と音。1 番（0.4）が許せるか | 押す面 3.6 のままでよいか（`POCKET_DEPTH`・`TAB_T`） |

### 3. latch: 掛かり方

`coupon_latch_frame` ＋ `coupon_latch_base` ＋ `coupon_latch_caps`。キャップの上面の点と枠の縁の点が同じ番号の穴に入れる。

| 番号 | 形 | 刷る向き | 押す面 | 狙い |
|---|---|---|---|---|
| 1 | つば F・厚さ 0.4 | 下面が下 | 3.6 | **本番の案**。掛かる面は上向きの面 |
| 2 | つば F・厚さ 0.6 | 下面が下 | 3.4 | つばを厚く（押す面が 0.2 下がる） |
| 3 | 45° の足 C・首 0.4 | 上面が下 | 3.4 | 掛かる面を斜面に（垂れない） |
| 4 | 45° の足 C・首 0.6 | 上面が下 | 3.6 | 同上 |
| 5 | 平らな足 S・首 0.4 | 上面が下 | 3.4 | 販売者と同じ形（掛かる面が宙に張り出す） |
| 6 | 平らな足 S・首 0.6 | 上面が下 | 3.6 | 同上 |

| すること | 見るもの | 決まること |
|---|---|---|
| 刷り上がりを見る | 5・6 番の足の付け根（掛かる面）が垂れているか。1・2 番のつばの上面はきれいか | F でよいか |
| 組んで、軽く押して離す | 戻るか。3・4 番は斜面で片側に寄って引っ掛からないか | 掛かり方 |
| 浮きを比べる | 押す面が同じ組（1・4・6 は 3.6、2・3・5 は 3.4）で、がたが同じか。違えば、その形は高さが設計どおりに出ていない | 高さの出方 |
| 上面を比べる | 1・2 番（刷る向きの上）と 3〜6 番（ベッドの面）の見た目・指ざわり | 上面の仕上げ |
| 指の爪でこじる | 抜けないか。つばが折れないか（1 番は厚さ 0.4 = 2 層） | つばの厚さ |

### 4. wide: 幅の広いキー

`coupon_wide_frame` ＋ `coupon_wide_base` ＋ `coupon_wide_caps`。台は中心に 1 個だけ（スイッチ 1 個で支える想定）。

| すること | 見るもの | 決まること |
|---|---|---|
| 真ん中を押す | 普通のキーと同じか | — |
| 端を押す | シーソーのように傾く量。反対の端が浮いて枠に引っ掛からないか。押した側が板に着かないか（計算では 2.25u で 1.4° 傾き、押した側が 1.0 下がる） | スイッチ 1 個でよいか・2.25u に 2 個要るか（open-gaps #5・#17） |
| 端を押したまま離す | 引っ掛からずに戻るか | 同上 |
| キャップをねじる・曲げる | 2.25u の板が柔らかくないか | キャップの厚さ |

### 5. strip: 枠の反り

`coupon_strip_frame` だけ（板もキャップも無い）。本番の枠は幅 286 で、A1 mini では 2 枚（約 143 ずつ）に分ける。その 1 枚の長さ。

| すること | 見るもの | 決まること |

## 6. ねじの試し刷り（coupon_screw・**基板を頼む前に刷る**）

**何のために**: 枠と基板は、基板の下から M2×4 のねじを**枠の樹脂に直にねじ込んで**留める。ねじ穴のまわりの樹脂は薄い（内側 0.7 mm）。
割れたり空回りしたりするなら、基板の穴の位置を変えるしかないが、**基板は頼んだ後では直せない**。だから先に、同じ形を小さく刷って締めてみる
（1 回目の監査 E 重要 2・open-gaps #33）。絵: `build/cckb-click/coupon_screw.png`。

### 何を刷るか

| | |
|---|---|
| ファイル | `build/cckb-click/coupon_screw_plate.stl`（4 つの部品を 1 枚に並べた物） |
| 中身 | **枠の切れ端 2 つ**（本番の枠から切り出した壁。長い方 = 奥の壁でねじ穴 3 つ・短い方 = 左の壁でねじ穴 1 つ）と、**当て板 2 枚**（基板の代わり。厚さ 1.6・穴 φ2.2） |
| 時間・材料 | 0.4 ノズル: 造形 約 22 分（準備込み 約 28 分）・2.5 cm³（約 3 g）。2026-10-04 に Bambu Studio と OrcaSlicer の両方でスライスした値 |
| ほかに要る物 | **スリムヘッド小ねじ M2×4 を 4 本**（本番と同じ物。docs/shopping-list.md）・精密ドライバー・ノギス |

### どう刷るか

最小の一式（上の 2 章）と**同じ**: A1 mini・0.4 ノズル・Bambu PLA Basic・設定 `cckb-click precise 0.10 @A1M 0.4`・回さない・サポートもブリムも無し。
枠の切れ端は上面が下（ねじ穴が上を向く）。当て板は平らに。**本番の枠を刷るのと同じフィラメントで刷る**（色や銘柄が違うと割れ方が変わる）。

### ねじ穴の番号

| 番号 | どこ | 壁の形 | 下穴の内側の肉 |
|---|---|---|---|
| 1 | 長い方の、角を落としていない側の端 | **本番と同じ** | 0.7 |
| 2 | 長い方の真ん中 | **本番と同じ**（1 と同じ。ばらつきを見る） | 0.7 |
| 3 | 長い方の、**端の角が斜めに落としてある側** | 比べるために、壁を 0.5 厚くした（本番の形ではない） | 1.2 |
| 4 | 短い方 | **本番と同じ**・壁を厚くする幅が狭い所（幅の広いキーの脇の 3 本がこの形） | 斜めに 0.49 |

### すること

1. 冷めてから外す。枠の切れ端を、ねじ穴を上にして机に置く。
2. **締める前に見る・測る**: ねじ穴のまわりに割れ・すき間が無いか。ノギスで、ねじ穴の所の壁の厚さ（外の面から内の面まで）を測って控える。
3. 当て板を載せる（穴を合わせる。長い方に長い板・短い方に短い板）。**押さえ付けない。**
4. ねじを 1 本ずつ、当て板の穴から入れて締める。**止まった所から 1/8 回転まで。**それ以上回さない。
   締めている間に、当て板が浮くか・最後に座るかを見る。
5. 4 本とも締めたら、壁を見る・測る（2 と同じ所）。
6. **全部ゆるめて抜き、また締める。これを 5 回**（本番で分解して組み直す回数の見込み）。毎回、止まる手応えがあるかを見る。
7. 5 回目に締めた状態で、当て板をつまんで枠から引きはがす向きに**軽く**こじる。

### 何を見るか・結果の意味

| 見る所 | こうなら | 意味・次にすること |

| 1・2 の壁 | 内側（薄い方）に**割れ・白い筋**・0.1 を超える膨らみ | 内側の肉 0.7 では足りない。3（1.2）を見る ↓ |
