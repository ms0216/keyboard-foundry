## 結論

**「上へ抜けない」は形で満たせた。「わざとでないと開かない」は、いまの蓋より形で決まる部分が増えたが、形だけでは言い切れない。刷って決める。**

- 掛けた蓋は、板ばねを押し切っても・板ばねが折れても、**右へ 1.45 ずらすまで上へ抜けない**（立体を 6 つの向きに動かして探した）
- 板ばねに触れなければ、蓋は右へ **0.25 までしか動かない**（板ばねの鼻に、直角の面で当たる）
- 板ばねを押せる所は、蓋の右の外にある幅 1.0 の溝の中。**そこにある物が蓋を押せる向きは、左（閉まる向き）だけ**。
  開けるには「溝の中で奥へ押す物」と「蓋を右へ動かす物」が別々に要る = いまの蓋の「1 回の擦り」では開かない
- **言い切れない所:** 板ばねを押す力は 0.7〜0.9 N と小さい。細い物が溝に入って板ばねを押し、同時に別の物が蓋の上面を右へ擦れば、蓋は右へずれる
  （その後、上へ持ち上げる 3 つ目の動きが要る）。鞄の中でこれが起きるかは、刷って擦って見る
- **S がいまの蓋より悪い所**（下の表）: 蓋の胴の応力・見える隙間・枠の刷りの危険（橋が 2 つ）・開け閉めに両手の指が要る

## 刷り方

- `coupon_cover_slide_plate_n04.gcode.3mf`: A1 mini・0.4 ノズル・層 0.1・PLA・支え無し。**造形 36 分 54 秒（準備込み 43 分 22 秒）・4.40 cm3・5.55 g**・6 個
  （枠の切れ端・当て板・電池の代わり・蓋 3 つ）。当て板と電池の代わりは、いまの蓋の試し刷りと同じ物
- **刷り方を 1 つだけ変えてある: 橋の向きを板の前後に固定（`bridge_angle = 90`）。**自動のままだと、板ばねの溝の底の橋が、長い方（左右 9 mm）へ渡る
  （G-code で見た）。**Bambu Studio で STL から切り直すときは、この設定を入れること。**渡した `.gcode.3mf` は、入れて切った物
- 回した検査: 立体の検査 16 件（`tests/test_cckb_click_cover_slide.py`）・スライスと G-code の検査（設定 26 個・警告 0・支えの線なし）。
  **回していない検査: 刷った物での全部**（留まるか・固さ・擦る・振る・落とす・回数）

## 検討で分かったこと（次に形を変えるときに効く）

- **横ずらしの蓋は、左右の足で電池を受けられない。**蓋を 1.6 右で落とすので、左の足（電池の円のすぐ外まで詰めた塊）が電池の上に載る（検査が見つけた）。
  電池と同じ中心の丸い面を残せるのは、真ん中の左 1.3 ほどまで（検査が立体で見る）→ 真ん中で受けるしかなく、蓋の胴の曲げが大きくなる。これが、S の応力が悪い理由
- **ずらすと、蓋の一部がクリップの板の下を通る。**耳より奥の部分は、板の外（x ≤ 113.35／≥ 130.65）にいなければ、上から落とせない
- **蓋を手前の面をベッドに刷る限り、平らな受け面の耳は作れない**（縁の裏に入る耳が宙から始まる）。S の蓋は上面をベッドに刷る
- **上面をベッドに刷ると、蓋に板ばねを置けない**（長さ 7 mm 以上が要り、電池の力を運ぶ手前の板が切れる）。留めのばねは枠の側に置いた
- **ずらす分の隙間は、どこかに必ず見える**（落とす位置で蓋がいた所が、掛けると空く）
- **薄い舌を軸の向きに押すと座屈する**（厚さ 0.6 × 幅 0.9 × 長さ 8.3 で 1.6 N）。板ばねは、高さを取れる向き（ベッドから立つ板）にした
- 決定記録が横ずらしを捨てた理由「掛かりを作れるのは片側だけ」は、離れていく側に「奥の壁から出た出っ張り」を置けば成り立たない

## まだ確かめていないこと

| 項目 | 理由 |
|---|---|
| 刷った物で、留まるか・固さ・擦る・振る・落とす・20 回の開け閉め | 刷っていない。見る所は `coupon_cover_slide_howto.png` の a〜l |
| 板ばねが、溝の底（橋）に付かずに刷れるか | G-code では 0.4（4 層）離れている。橋の垂れは刷って見る。**刷り上がったら、まず板ばねを爪で押して見る** |
| つぶれる筋の固さ（手で左へ寄せ切れるか）・何回で削れるか | しめしろは計算。筋は、蓋が横から擦って乗る |
| 細い物が溝に入り、別の物が蓋を右へ擦って開くことが、鞄の中で起きるか | 形では防げていない。利用者が擦って決める |
| 蓋の胴が、電池に強く押されて白くならないか | 圧縮 55 MPa は曲げ強さ 76 の 1/1.4。1500 G は借りた仮定 |
| 本物のクリップで、上の板（下面 4.3）とクリップの上（公差の端 4.35）が当たらないか | いまの蓋と同じ未解決。当て板にクリップの板の代わりは無い |
| 左右の空洞（基板まで抜けている所）の下の基板の面に、裸の銅が見えないか | 見ていない（本番に採るときに、基板の検査に足す）。右の空洞の右半分と、板ばねの溝には底がある |
| キャップ・電源スイッチのつまみとの取り合い | 変えた範囲は口のまわりと右の壁の上面だけで、つまみの切り欠きは範囲の外（検査）。キャップは変えた範囲に無い |

## 本番に採るなら要ること（いまは何もしていない）

- 寸法を `spec.py`（`[暫定]`）と `click_layout.cover` に移し、`click_case` の枠・蓋・試し刷りを置き換える（置き換えられた落とし込み式の名前を、コード・生成物・記録から消す）
- 右の枠の刷り方に `bridge_angle = 90` を入れてよいかを、枠全体の橋で見直す
- 決定記録を書く（この文書は試し刷りの説明で、決定ではない）
- **基板を変える提案は無い。**S は基板を変えずに成り立つ。蓋の胴の応力を下げるには、蓋の奥行きを増やすしかなく、それを止めているのはクリップの板
  （基板の上 3.5〜4.35）で、基板の形ではない
