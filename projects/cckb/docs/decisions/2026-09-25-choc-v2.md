# スイッチを Kailh Choc V2（PG1353）に替える——事実の洗い出しと、スタビ・高さ・基板の決め方（下書き）

- **日付:** 2026-09-25
- **状態:** 下書き。**`cckb-v2` の枝で核・プレート・基板（§10）、プレートの欠けの直し・ケース・キャップ・小片（§10-6・§10-7、2026-09-26）まで V2 にした**。**スタビの穴は §10-9（2026-09-26・利用者と決めた）**。見本で確かめること（§10-5）が残る。
  main は V1 の完成した設計のまま（利用者が 2 つを比べて選ぶ）
- **決めた人:** 利用者（V2 に替えること）・Claude（事実の調査と、この記録の案）

**結論（案）**

1. **基板の端子の位置は変わらない。**kiswitch の `SW_Kailh_Choc_V2` の端子は (0, −5.9)・(5, −3.8) で、いまの V1 の足跡と同じ。
   Kailh の図面 CPG135301D01 の推奨穴から、V1 と同じ手順（パターン側 → 部品側）で変換し、V2 の十字は 90° ごとに対称なので
   180° 回した向きで一致する（§2-3）。**ただし穴が 2 つ変わる**: 中心穴 φ3.45 → **φ5.05**、ボス φ1.9 ×2 → **位置決め穴 φ1.6 ×1（−5, 5.15）**。
   この φ1.6 が**行のバス（キー中心の 4.3 下）に 62 キー全部で当たり**、基板の下の**支え 5 本にも当たる**（§5）。配線は引き直しになる。
2. **スタビは遊舎工房の「Choc v2用スタビライザー 2U（スクリュータイプ）」**（SKU A050001-01-1・¥330・在庫あり）を 4 個。
   基板 1.6mm にねじで留める型で、プレートには掛からない（§3）。
3. **厚さはキャップの上面で 13.8 → 14.7（+0.9）**が既定の案。内訳はスイッチの背 +0.6 と、基板の下の空き 1.8 → 2.1（+0.3）。
   V2 の中心の突起（φ4.8・ハウジングの下面から 3.30）が、基板が薄い側（1.44）で基板の下面から 1.96 出て、いまの空き 1.8 に収まらない。
   床に 66 個の穴を開ければ 14.4（+0.6）で済む（§4。**どちらにするかは利用者が決める**）。
4. **キャップの天板の下限は変わらない（1.2 = 0.4 × 3）。**キャップを V2 用にすると、ステムの「十字を受ける筒」が要る（§6）。

> スタビは非公式の図面しか無い。スイッチの下面の 0.30±0.2 の突起は何なのか分からない。

## 1. なぜ決める必要が生じたか

利用者が 2026-09-25 に、Choc V1（PG1350）から V2（PG1353）へ替えると決めた。理由（利用者の観察）は次の 3 つ。

- V1 は終わりに向かっている様子がある（kailh.net のデータシートの頁に V2 しか載っていない。**この記録では確かめていない**）。
- V1 を選んだ当初の理由が 2 つとも消えた。CFX のキーキャップはやめて自分で刷る（D14）。ホットスワップのソケットもやめて直付けにした（D3）。

基板はまだ発注していない。この段では**事実を集めて決め方を固める**。コード・基板・ケースは次の段で変える。

### 2-2. V1 との差（高さ）

- ステムの上面は **+0.60**（8.00 → 8.60）。プレートの上面の高さ 2.20 は同じ。
- 押し切ったときのステムの上面は 8.60 − 3.2 = **5.40**（V1 は 8.0 − 3.0 = 5.0）。つまり押し切りでも +0.40。
- ステムはハウジングの上に 3.30 出る。ストロークの上限 3.45 まで押すと、ステムの上面はハウジングの上面より 0.15 下がる。
  **平らなキャップはハウジングの上面に当たって 3.30 で止まる**（ストロークの公差の中）。止まる所はキャップの形で決まる（§6）。

### 2-3. 端子の位置（基板の配線を残せるか）

V1 で確かめた変換（tests/test_choc.py の `_to_kicad`: X を反転 → +90° → Y を反転）を V2 の推奨穴にそのまま当てた。

| | 図（パターン側） | `_to_kicad` の後 | さらに 180° 回す | kiswitch `SW_Kailh_Choc_V2` |
|---|---|---|---|---|
| 端子 | (+5.90, 0) | (0, +5.90) | **(0, −5.90)** | pad 1 (0, −5.9) |
| 端子 | (+3.80, +5.00) | (−5.00, +3.80) | **(5.00, −3.80)** | pad 2 (5, −3.8) |
| 位置決め φ1.6 | (−5.15, −5.00) | (5.00, −5.15) | **(−5.00, 5.15)** | 穴 1.6・ランド 2.6（スルーホール・網なし） (−5, 5.15) |
| 中心 | φ5.00 | | | NPTH **φ5.05** |

- **180° 回してよい理由**: V1 で +90° が要ったのは、キャップの脚 2 本（横並び）とステムの穴の向きを合わせるためだった。
  V2 の十字は 4.00 × 1.30 が 2 方向で同じ（90° ごとに対称）。だからスイッチはどの 90° の向きで座ってもキャップは挿さる。
  鏡映（左右反転）はしていない。X と Y を 1 回ずつ反転しているので、全体では回転になる。
- だから **V2 の端子は V1 の足跡の端子とぴったり同じ位置に置ける**。列の配線（端子 1 から）とダイオードへの L 字（端子 2 から）は形を残せる。
- 同じ向きの足跡を持つライブラリが 2 つある:
  - kiswitch（perigoso の後継）`library/footprints/Switch_Keyboard_Kailh.pretty/SW_Kailh_Choc_V2.kicad_mod`
    （<https://github.com/kiswitch/kiswitch>。V1 版はいまの `lib/keyswitch.pretty/SW_Kailh_Choc_V1.kicad_mod` と一字一句同じ）。
  - サリチル酸さんの `kbd_SW.pretty/Choc_v2.kicad_mod`（<https://github.com/Salicylic-acid3/KiCAD_FootPrint>）。
    端子 (0, 5.9)・(−5, 3.8)・中心 φ5.0 で、`_to_kicad` の後と同じ向き（kiswitch を 180° 回した物）。位置決めは (5, −5.55) の長穴で、図の 5.15 と 0.4 違う。**図に合うのは kiswitch**。
  - Keebio `MX-Alps-Choc_V1V2-1U-NoLED-Alt` は MX・Alps と兼用の穴で、単独の照合には使わない。
- **中心穴 φ5.05**: 図の推奨は φ5.00、突起は φ4.80 で、片側 0.10〜0.125 の隙になる。kiswitch の 5.05 を使う（JLC の穴の公差でも入る側）。

## 4. 高さ（spec の数値から計算）

### 4-1. 基板の下の空き（いま `UNDER_PCB` = 1.8。床の上面から基板の下面まで）

基板の上面から下へ出る物を、基板の下面から測り直した。JLC の基板 1.6 は ±10% で、最小 1.44。

| 物 | 基板の上面から下へ | 基板の下面から（1.6） | 最悪（基板 1.44・長さは公差の上限） | 1.8 に対して |
|---|---|---|---|---|
| V1 の足（いま） | 3.00（+0.10） | 1.40 | 1.66 | 0.14 空く（いまの根拠） |
| V2 の足・位置決め | 3.00（**±0.2**） | 1.40 | 1.76 | 0.04 |
| **V2 の中心の突起 φ4.8** | 3.30（±0.10） | 1.70 | **1.96** | **−0.16（当たる）** |
| **スタビ A の箱** | 3.30（公差は不明） | 1.70 | **1.86** | **−0.06（当たる）** |
| スタビ A の爪 | 2.65 | 1.05 | 1.21 | 0.59 |
| スタビ A のねじの頭 | ―（下面から） | 1.15 | 1.15 | 0.65 |

### 4-3. プレートの厚さ（V2 で決め直し）

V1 はつばの下から爪の先までが 1.30 で、プレート 1.2 が 0.1 の遊びで挟まった。V2 はここが **1.65** ある。
1.2 のままだとプレートが 0.45 浮く。スイッチは基板にはんだ付けするので位置はずれないが、プレートがカタつく。
0.2 層で刷れる厚さなら **1.4（遊び 0.25）か 1.6（遊び 0.05）**。プレートの上面は 2.2 のまま動かないので、厚くしても全体の厚さは変わらない。
プレートの下面と基板の間は 1.0 → 0.8 / 0.6 に減る。そこに入る物（ナット 1.6 はプレートの六角の穴に入る・角は開口）は、次の段で確かめる。
スタビ A は厚さを縛らない（2.2 まで）。**試し刷りの小片で決める**（1.2 / 1.4 / 1.6）。
スイッチの開口は、下のハウジングの 13.95±0.05 を挟んで小片で 13.90 / 13.95 / 14.00 / 14.05 を比べる（V1 は図の 13.80 と同じ値を開口にした）。

### 10-3. スタビの図が非公式であることと、支点の 24.0 / 23.8

> **2026-09-26 に §10-9 で置き換えた**: 販売者の足跡（実物の実測）を正、図を参照にし、支点 ±11.9・丸穴 φ3.0 / φ4.0 に。下の「和で開ける」は前の考え方の記録。

- **E 重要 2（ねじの頭）**: 図の断面で頭 φ3.7・厚さ 1.5（[暫定]）。床の内側に頭の下の止まり穴 8 個（φ3.7 ＋ 片側 0.4・深さ 0.4）を足した（止まり穴は 264）。
  頭の下の床まで 0.3 → 穴の底まで 0.7。組み立てモデルの頭も φ3.7 × 1.5 に。
- 組み立てモデルのスタビ: 爪・ワイヤを足跡の 8.24 に、押したときは箱の上面の口（5.5 角）が行程だけ空く。

**配線（スタビのキーの周り）**: 板の生成し直しと `route_pcb.py --reroute`（監査の済んだ配線は持ってくる）。
- 行のバス: 箱の穴とねじの穴の禁止域の下を回る。回り道の高さはスタビのキー 4 つともキーの中心の **8.95 下**（バスから 5.6 下。前は 8.35 下）。スペースでは基板の縁（9.825 下）の配線禁止の帯まで線の縁から 0.46。`matrix_routes` の計画のまま引けた（禁止域の円を障害物に足した。板から数えた）
- 左 Shift の左のねじの穴の禁止域が XIAO の奥の列のパッドのすぐ上に来て、VBAT_SW（R_HI への枝）・V3V3（XIAO の 3V3 へ）・SPI_MOSI（D10 へ）の
  通り道を塞いだ（禁止域の下とパッドの上の間 0.73 に、3V3 と D10 へ上から入る 2 本が表で交わる）。Freerouting は余裕 30µm で 3 本引けないまま 14 回回った。
  **決まった形で引いた**（`spec.FIXED_RUNS`・`matrix_routes.fixed_runs`）: VBAT_SW は箱の穴の右を上がり、箱の穴と爪の禁止域の間（y −14.1）を左へ回って R_HI へ（約 30mm 長い・0.3 幅で 0.05Ω）。
  V3V3 は裏で禁止域の下をくぐり、3V3 のパッドの上でビアを立てる。SPI_MOSI は前の表の形のまま、裏の線の端でビアを立てる
- Enter の左の行 2 の回り道が、Freerouting が前に引いた COL14 の裏の線（y −9.14）と重なった（DRC の短絡 1）。COL14 だけ Freerouting で引き直した

## 検討して捨てた案

| 案 | 捨てた理由 |
|---|---|
| スイッチを 90° / 270° に回して、位置決め穴をバスから逃がす | どの向きでも端子か位置決め穴がキー中心の 4〜6 下の帯に来る（§5）。端子の位置も変わり、列の配線まで引き直しになる |
| サリチル酸さんの足跡（端子が下・位置決め (5, −5.55)） | 位置決めが図の 5.15 と 0.4 違う。端子も V1 と逆向きで、配線を残せない |
| スタビ C（Gateron KS-57）・D（V1 のスタビを流用） | §3-2。高さ（2.35 / 0.6 低い）と行程 3.2 を満たすか確かめられない。D はプレートを 1.2 に縛る |
| 中心の突起を切る | 62 本。切り口の高さがばらつき、手間も大きい |

## この決定が乗っている前提（動いたら読み直す）

- スイッチは直付け（D3）・基板 1.6（O3）・床 1.2（O10）・キャップは自分で刷る（D14）。
- スタビの寸法はメーカーの公式の図ではなく、販売者が公開した抜粋に乗っている。公式の図が出たら突き合わせ直す。
- 高さは「ハウジングの下面が基板に着く」読みに乗っている（§8 の未確認 1）。
