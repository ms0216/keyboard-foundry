# キーキャップの天板をステムの上だけ膜 0.6 にする（上面 14.4 → 13.8）

- **日付:** 2026-09-28
- **状態:** 決定（利用者）。**ただし見積りでは縁を押すとステムのまわりの輪が割れる（§4）。coupon_skin で確かめるまでキャップ一式は刷らない**
- **決めた人:** 利用者（膜 0.6・外は下へ 1.0・押し切りで何にも 0.1 残す）。形・数の導き方・小片は Claude（枝 `cckb-keycap-skin`）

## 1. なぜ決める必要が生じたか

天板はステムの上面から一様に 1.2（`KEYCAP_TOP_T`）で、キャップの上面は机から 14.4。利用者の考え:
ステムの真上の天板は下からステムの上面に支えられるので曲げの硬さが要らず、薄くできる。硬さが要るのは
ステムから離れた所（キーの縁）だけ。そこで

- ステムの上の膜 **0.6**（上面 = ステムの上面 ＋ 0.6）
- それより外は下へ **1.0** まで厚くする。ただし押し切り（行程の最大 3.05）で天板の下面が、ハウジングの上面 5.30・
  静音のつば 5.70（φ7.9）に **0.1 以上**残る所だけ。つばの輪とステムの上は膜だけ
- 筒（十字を掴む）は膜から下げ、掴む深さはそのまま。2.25u のスタビの受け口も新しい天板に合わせる

## 3. 積み上げ（spec の数から。机 = 0）

| | 前 | いま |
|---|---|---|
| 床 `CASE_FLOOR` | 1.2 | 1.2 |
| 基板の下の空き `UNDER_PCB` | 1.8 | 1.8 |
| 基板 `PCB_T` | 1.6（上面 4.6） | 1.6（上面 4.6） |
| ステムの上面（＋ 8.6） | 13.2 | 13.2 |
| **キャップの上面（＋ `KEYCAP_TOP_T`）** | **14.4**（＋ 1.2） | **13.8**（＋ 0.6） |
| 縁（基板 ＋ 7.0） | 11.6 | 11.6 |
| 押し切ったキャップの上面（− 3.05） | 11.35（縁より 0.25 低い） | **10.75（縁より 0.85 低い）** |

押し切ったキャップが縁より低いのは前からで（0.25）、深くなっただけ。縁（壁の上面）はキャップの外 1.3 以上離れた幅 1.3 の帯で、
端のキーの外の縁を指先で押し切ったとき、指が縁に触れて止まるかもしれない程度（`section_keycap_rim_pressed.png`）。
鞄の中で押されにくくなる向き。指で確かめてはいない（組んでから端のキーを押して見る）。

天板の場所ごとの厚さ（`keycaps.plate_levels` が spec から導き、層の倍数に切り下げる）。上面は基板の上 9.2:

| 場所 | 上限 = 9.2 −（障害物 ＋ 0.1 ＋ 3.05） | 層で切り下げ | 押し切りの隙 |
|---|---|---|---|
| ステムの上（φ6.5 の内） | ―（下面 = ステムの上面・ステムと一緒に動く） | **膜 0.6** | ― |
| ハウジングの上（13.95 ＋ 片側 0.2。1u はスカートまで） | 9.2 − 8.45 = 0.75 | **0.6** | 0.25 |
| つばの上の輪（φ6.5〜8.7） | 9.2 − 8.85 = **0.35** | **0.2（1 層）** | 0.25 |
| それより外（1.5u 以上の両脇・スタビの上） | スタビの箱 9.2 − 8.15 = 1.05 | **1.0** | 0.15 |

- **つばの上の輪は膜 0.6 にできない**: 押し切るとステムの上面は 8.60 − 3.05 = 5.55 まで下がり、つばの上面 5.70 より
  0.15 下に入る。膜をつばの上まで 0.6 にすると押し切りでつばに 0.15 当たる（前の案で 0.25 の窪みを彫っていた理由）。
  上面を 9.2 にしたままつばに 0.1 残すと、輪は 0.35 まで。0.35 は 0.2 層で 2 層目の真ん中（0.3）が中に入るので 0.4 に刷られ、
  隙は 0.05 になる。だから 1 層 0.2 に切り下げた。
- **ハウジングの上も 1.0 にできない**: 上限 0.75 を層で 0.6。1u はハウジングの逃げ（片側 7.175）とスカートの内側（7.275）の
  間が 0.1 しか残らないので、逃げをスカートまで広げた（`KEYCAP_PLATE_MIN_W`）。**1u に 1.0 の所は無い**。
- スタビの受け口: 台（φ5.1）の下端はステムの上面から 2.0 のまま（掴む深さそのまま）。台は 1.0 の天板から下がる。
  十字の穴の上に残す天板 0.6 → **0.4**（`STAB_SOCKET_TOP_KEEP`）で、穴の上端は軸の上端の 0.2 上。
- スカートの下端は動かさない（ステムの上面から 1.0 下）。見える側面は 2.2 → 1.6。
- 62 個の体積 35.2 → 22.2 cm³（約 −16g）。

## 4. 曲げ・抜き差しの見積り（`projects/cckb/tools/keycap_bending.py`）

### 4-1. 梁（前の見積りと同じ方法）

片持ちの梁。支えから縁まで x で切った断面（天板＋スカート）の I(x) を刷る形から測り、縁に 3 N、δ = ∫P(x_e − x)²/(EI) dx。

| | 前（1.2） | いま | 比 |
|---|---|---|---|
| 1u スカートあり（支え = ステムの外周 3.25 → 縁 9.0） | 13.9 µm・5.1 MPa | 41.8 µm・11.4 MPa | 3.0 倍 |
| 1u 天板だけ（両脇のスカートを除く） | 34.5 µm・5.9 MPa | 282.7 µm・26.2 MPa | 8.2 倍 |
| 2.25u スカートあり（支え = スタビの台の外周 14.45 → 縁 20.9） | 19.4 µm・5.4 MPa | 43.9 µm・8.5 MPa | 2.3 倍 |
| 2.25u 天板だけ | 46.2 µm・5.2 MPa | 79.8 µm・7.4 MPa | 1.7 倍 |

### 4-2. ステムのまわり（梁では見えない所）

**曲げの力がいちばん大きいのは縁ではなく支え（ステム）のまわり。**縁の荷重は、筒へ渡るとき必ず
つばの上の輪（r 3.25〜4.35）を通る（輪より内は膜と筒しか無い）。梁は断面を x で切るので、この集まりが見えない。
そこで円板（Kirchhoff・ν 0.35）を r の 1 次元の有限要素で解いた: 内の縁 = 筒の外周 r 2.75 を固定、1u の縁の真ん中
r 9.0 に 3 N、スカートは入れない（縁は自由）。厚さは `plate_levels` の値。

| 膜 | 上面 | 輪 | 縁のたわみ | 最大の曲げ応力（輪の内の縁） |
|---|---|---|---|---|
| 前 1.2（窪み 0.95） | 14.4 | 0.95 | 48 µm | **10.0 MPa** |
| **0.6（いま）** | **13.8** | **0.2** | **1019 µm** | **117.5 MPa** |
| 0.8（控え） | 14.0 | 0.4 | 290 µm | 43.2 MPa |
| 1.0 | 14.2 | 0.6 | 119 µm | 22.0 MPa |
| 1.2（新しい式） | 14.4 | 0.8 | 60 µm | 13.2 MPa |

- 一様な板で検算: 厚さ 0.6 と 1.2 で応力の比 4.0（1/t²）・たわみの比 7.9（1/t³）。1.2 のたわみ 38 µm は梁の「天板だけ」34.5 µm と同じ桁。
- **縁に爪をかけて片側からこじって抜くのも、同じ形（荷重の向きが逆なだけ）**。抜く力は測っていない（Choc V2 の十字の保持力の公開値は見つけていない）。
- 引張強さ 39 MPa に対して、0.6 は 3 N で約 3 倍、0.8 は約 1.1 倍。**1.0 で約 0.56 倍、前の 1.2 で約 0.26 倍**。
  繰り返しの荷重（打鍵）では静的な強さより低いところで割れる。

**結論（見積り）: 利用者の決めた形（膜 0.6・輪 0.2）は、キーの縁を押すと輪から割れる恐れが高い。**
「ステムの上は支えられるので薄くてよい」は膜の真ん中（φ5.7 の内）には当たるが、支えのすぐ外の輪は、
縁からの曲げをすべて筒へ渡す所で、しかもつばの逃げのためにいちばん薄くなる所。

## 5. 小片 coupon_skin（本番の 1u を膜 0.6 / 0.8 / 1.0 で）

- 本番の 1u のキャップを `KEYCAP_TOP_T` だけ替えて 3 個（場所ごとの厚さは同じ式。輪は 0.2 / 0.4 / 0.6）。スカートの手前の下端に
  切り欠き 1 本 = 0.6・2 本 = 0.8・3 本 = 1.0。A1 mini で 12 分・1.14 cm³。
- **0.6 と 0.8 は利用者の決定。1.0 は §4-2 の見積りで引張強さの半分を下回る最初の厚さとして Claude が足した。**
- やること: 静音のスイッチに挿し、天板の縁に爪をかけて 10 回抜き差し・縁の真ん中を指で強く押す（10 回）。
  膜・輪が割れないか・白くならないか・筒が取れないか・押したたわみが気にならないか。
- 割れなかった一番薄い物を `spec.KEYCAP_TOP_T` にし、`case.py` で出し直す（全体の厚さは 13.8 / 14.0 / 14.2。検査の上限
  `tests/test_cckb_interface.py` の 13.8 も直す）。膜は 1 つの定数。

## 7. 刷り方

キャップは天板をベッドに刷る（上下を返す）。膜は 1〜3 層目・輪は 1 層目だけ・ハウジングの上は 1〜3 層目・外は 1〜5 層目。
輪は 1 層目の上に何も載らない所で、上から見ると膜の中に φ6.5〜8.7 の輪が透けて見えうる（白い PLA は透ける）。

## 検討して捨てた案

| 案 | 捨てた理由 |
|---|---|
| 輪も膜 0.6（つばの上を彫らない） | 押し切りでつばに 0.15 当たる（利用者の条件 0.1 の隙を割る）。壊す検査で当たることを見た |
| 輪を 0.35 で設計 | 0.2 層で 0.4 に刷られ、隙 0.05（条件割れ） |
| ハウジングの上を 0.75 で設計 | 同じく 0.8 に刷られ、隙 0.05 |

## この決定が乗っている前提（**動いたら読み直す**）

- 行程の最大 3.05（静音）・つば 5.70・φ7.9・ハウジング 5.30 と上の胴の平面（包絡 13.95 角）。見本で上の胴が小さいと分かれば、
  逃げを狭めて 1u にも 1.0 の帯を残せる
- 0.2 層で刷る（層を変えると `PRINT_LAYER` を直す。輪の厚さが変わる）
- スタビの軸の上端 = ステムの上面（どちらも 8.60）

## 覆す前に読むこと

§4-2。膜を厚くするときは `spec.KEYCAP_TOP_T` だけを変える（外・輪・ハウジングの上は式が導く）。
