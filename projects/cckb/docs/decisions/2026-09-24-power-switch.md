# 電源スイッチを秋月の SS-12D00G3（表・レバーが上）にし、右のふたの穴から爪で動かす

- **日付:** 2026-09-24
- **状態:** 決定（部品と置き方は利用者。寸法・配線・ケースの形はこの記録）
- **決めた人:** 利用者（部品と置き方の案）・Claude（寸法と検査）

**結論**: 電源スイッチを LCSC の MK-12C02-G025（C778186・基板の裏・横へ出るつまみを右の側面の窪みから操作）から、
秋月電子の **SS-12D00G3**（115707・¥20・スルーホール・レバーが上）に替えた。**基板の表の右の縁**に長辺を y に向けて置き、
レバーは**右のふた（電池のふた）の穴**の中に来る。先はふたの上面より名目で 0.1 下（出っ張らせない）で、爪で上から押す。
**奥へ押すと入**（ふたに「ON ↑」を彫った）。電池ホルダは**左へ 3.8** 寄せた。足は付けた後で基板の下面から 1.0 に切る。
板の変更は SW_PWR と BT1 の位置と、網 **VBAT_IN・VBAT_SW** の右の角の部分の配線だけ（ほかの 88 網は前の板と同じ）。

図: `build/cckb/psw_section.png`（断面・スイッチを 1 つの部品として囲んだ）・`build/cckb/psw_corner_iso.png`（右の角・ふたを
持ち上げた）・`build/cckb/interface_corner_right.png`（平面と断面 B・C）

## 1. なぜ決める必要が生じたか

利用者が 2026-09-24 に決めた: 国内で買える品にする（前の品は LCSC で最小 5 個・送料が部品代より高い）。候補は
**SK-12D11VG3（横レバー）**・**LCSC の MK-12C02-G025（いまの品）**・**SS-12D00G3（上レバー）** の 3 つで、利用者が
SS-12D00G3 を上へ向けてふたの穴から操作する案を選んだ。横レバーの案は、前の検討でホルダを 5.5 動かす必要があり、
右の壁の切り欠きと窪みも残る（利用者の比較による。ここでは測り直していない）。

**爪の形の仮定**: 爪を「厚さ NAIL_T 1.0・幅はレバーと同じ」の箱として、穴の端から上に差し込む。実際の爪の先は曲がっていて、
穴の幅 2.4 の向きに置くと沈みは小さい。穴の長さの向き（y）に爪を立てて差す使い方を想定している。**刷って確かめる**（P4）。

## 4. 影響範囲（端から端まで）

- **回路**: CR1632 ＋ → BT1.1（VBAT_IN）→ SW_PWR.2（真ん中）→ 入で SW_PWR.1（奥）→ VBAT_SW → 分圧・D_PWR。SW_PWR.3 は空き
  （`circuit.py`・`foundry/pinmap.py` の `slide_ss12d00`。耳 4 つのパッドは無くなった）
- **基板**: SW_PWR（表・`lib/cckb.pretty/SW_SS-12D00G3`）を (141.225, −38.6)、BT1 を (124.7, −38.6)（前は 128.5）。
  網 VBAT_IN は表で ＋ のパッドから真ん中の足へ真っすぐ 4.4、VBAT_SW は裏の長い線（y −28.392）の右端 118.689 から
  133.517 まで伸ばして 45° で奥の足へ（Freerouting・`route_pcb.py --reroute VBAT_IN,VBAT_SW --clear 95.25,-47.925,143.175,-28.575`）。
  前の位置決めの穴（φ0.9 ×2）が無くなったので、**DRC の npth_inside_courtyard を警告に下げるのをやめた**（spec.DRC_SEVERITY を消した）。
  DRC 違反 0・未配線 0・警告 3（silk_edge_clearance・前と同じ 3 件）
- **発注ファイル**: BOM 4 行・CPL 69 行は変わらない（スイッチは前から手はんだ）
- **ケース**: トレイの右の壁の切り欠きと指の窪み、右のふたのひれを消した。右のふたにレバーの穴 6.4 × 2.4 と刻印「ON ↑」（深さ 0.4）
- **組み立てモデル**: 電源スイッチは表の 1 つの立体（本体・レバーの動く範囲・切った足）。爪の検査を上から入る形に書き直した
- **手順書・買い物**: 秋月で 3 個。ホルダを先に付け、スイッチは表から差して裏から付け、足を切る（assembly-guide 手順 3・4）

## 5. 決めたこと

上の結論のとおり。値は `spec.py` の `PSW_*`・`HOLDER_AT`、`case_spec.py` の `PSW_SLOT_*`・`PSW_MARK_*`・`PSW_NAIL_REACH`。

## 検討して捨てた案

| 案 | 捨てた理由 |
|---|---|
| 本体の長辺を x に置く | ホルダを 8.5＋隙 ほど左へ動かすことになり、柱との間 3.0（電池を取り出す指の場所）を割る |
| スイッチをホルダの左（柱との間）に置く | 空きは 10.5 あるが、電池を取り出す指・道具の入る側を塞ぐ。利用者の案は「右の角・ホルダを左へ」 |
| 足を切らずに床を掘る | 足の先は机から 0.9〜1.1 まで下がる。床 1.2 の中で止めると床が 0.1 前後しか残らない（肉厚の下限 1.2）。床に穴を開けると足が裏から見える |
| レバーの先を必ずふたの上面より下にする（縁を上げる・ふたの上に土手・レバーを切る） | どれも見た目・手間が変わる（利用者が決めること）→ O13 |

## この決定が乗っている前提（動いたら読み直す）

- 爪の出 0.4（[暫定]）。大きいとレバーがふたから出る（O13）、小さいと足の出が増える（切るので影響は小さい）
- 縁の高さ `RIM_ABOVE_PCB` 7.0・ふた 1.2（ホルダで決まる）。縁を動かすとレバーの先との差が動く
- 「レバーの側の足が共通と繋がる」（図の読み）。違ったら刻印の向き `PSW_ON` を反対にする（板はそのまま）
