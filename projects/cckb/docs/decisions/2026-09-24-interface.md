## 1. なぜ決める必要が生じたか

基板は発注すると直せない。基板・プレート・ケースが共有する寸法（角の部品の位置、ネジ穴、
スタビの逃げ穴、外形、電源スイッチ、アンテナの禁止域）を先に固め、基板の段（次）と
ケースの段（後）が手戻り無しに進めるようにする。open-gaps の #2（角の断面）と
O2〜O6 を閉じる。

### 2-2. 取付位置の探索（生成した基板の実物から）

`tools/kb cckb pcb` で作った基板を KiCad の Python で世界座標に解き（`projects/cckb/tools/board_geometry.py`・
パッド 434・部品 124）、0.5mm 刻みで 5 条件（下）を**同時に**見た（`projects/cckb/tools/find_mounts.py`）。
置ける点は 2,163、54 区画。**1u のキーが並ぶ所には 1 つも無い**（スイッチの間の桟 5.25 に、ナットの
六角の穴 4.2＋肉 1.2×2 が入らない）。置けるのは 1.5u 以上のキーの端と、角だけ。

探索の途中で自分の道具の誤りを 2 つ見つけて直した（検査を先に疑った）:
- 輪郭を広げる関数の符号が逆で**縮めていた**（スタビの逃げを 1mm 小さく見ていた）→
  `test_poly_offset_matches_build123d` で build123d と突き合わせる
- 高速化で絞ったパッドから配線の通り道を作り、**通り道が欠けて 5 か所を見逃した** → 通り道は基板全体から作る

1. 縁: 穴の縁から外形まで 1.0 以上
2. キーとプレートの開口: ナットの穴（二面幅 4.2 の外接円）のまわりに肉 1.2 を、スイッチ・スタビの開口・

3. 部品: 上はナット（外接円 2.31）、下はトレイのボス（φ5.6）が、パッド・足・穴・スタビの逃げ穴・

4. コートヤード: 穴のコートヤード（r 2.45）と表のコートヤード、ボスと裏のコートヤードが重ならない
5. 配線の通り道（設計書 §12）: 行（裏の横・ダイオードの ROW 側のパッドを結ぶ線）と列（表の縦・

### 2-4. たわみ（O3）

柱と取付の配置で、キーの中心から最寄りの支えまで最大 d = 21.5mm。両端支持の梁（幅 19.05・
スパン 2d = 42.9・中央集中荷重）で δ = F L³ / (48 E I)、I = b t³ / 12、E = 18.6 GPa（FR4 の保守側）:

| F | t = 1.6（I = 6.50） | t = 1.2（I = 2.74） |
|---|---|---|
| 3 N（強い打鍵） | 0.041 mm | 0.097 mm |
| 10 N（手のひら） | 0.136 mm | 0.322 mm |

足の先の最悪の余裕（基板 −10%・足 +0.1 で床まで 0.14）に対し、1.6 は 10N でも収まり、1.2 は超える。
全体の厚さは基板の厚さで変わらない（足は基板の**上面**から 3.0 出るので、薄い基板ほど下の空きが要る）。
→ **1.6**。代償は重さ +約 21g（289 × 99 × 0.4mm × 1.85g/cm³）。検査 `test_the_pcb_thickness_is_stiff_enough`。

### 2-6. スタビ（O2）

Keebio の輪郭（ハウジング 6.30×6.60＋奥行 0.25・切り欠き 0.4）を片側 0.5 広げて基板を切り抜く。
ハウジング（製造図の最大公差 6.32 × 6.60・突起 3.28）との隙は最小 0.5（外形公差 ±0.2 を引いて 0.3）。
ハウジングの高さ 4.30 で、上面がプレートの上面より下がることはない（上からはめて爪で留まる）ので、
下端は最も低くて 7.2 − 4.3 = **2.9**（基板の下面 3.4 の 0.5 下・床の上面 1.6 の 1.3 上）。
二次資料の「プレートの下に 2.5〜3.5 出る」の大きい方（プレートの下面から）でも 6.0 − 3.5 = 2.5 で
床の 0.9 上。**床に穴もくぼみも要らない**（厚くもしない）。実物ではめて確かめる（P1）。

## 4. 影響範囲（力と信号の流れに沿って）

- **打鍵の力**: キャップ → スイッチ → （はんだ）→ 基板 → 柱 38 本・取付のボス 9 → トレイの床 → 机。
  プレートはスイッチのはんだで基板に留まるだけで、力の通り道ではない
- **持ち上げる力**: トレイ → ネジ（下から）→ ナット（プレートの六角の穴で回り止め）→ 基板。
  トレイの左右はそれぞれ 4〜5 本のネジで基板に留まり、継ぎ目に力はかからない（D13）
- **電池の電流**: CR1632 → ホルダ（右の角・表）→ 電源スイッチ（右端・裏）→ 分圧・B5819W → XIAO の 3V3
  （左の角）。右端から左端まで約 250mm を基板で引く（直流・mA 級）
- **電波**: アンテナ（左の角の +x の端）→ 銅の禁止域（XIAO の中へ 3.14・外へ 5.0・幅 ±6.0）→ 樹脂のふた。
  左のふたのネジ H3 はチップから 6.6（要件 5）
- **利用者の手**: USB-C（左の側面）・電源スイッチ（右の側面の窪み）・電池（右のふたをネジ 1 本で外す）・
  ネジ（全部底面から）
- **foundry の核**: `foundry/plate.py` に 2 つ足した（`MOUNT_POCKET_AF` があれば取付をナットの六角の穴に、
  `PLATE_SPLIT` があればプレートを左右に分ける）。どちらも無い機種（HHKB）は挙動が変わらない
  （`tests/test_regression_hhkb.py` で確認）
- **基板の生成**: 取付穴 10 個が増えた（`MOUNTS`）。DRC 違反 0・警告 silk_edge_clearance 2（以前は 17。外形が 0.3 広がった）

## 5. 決めたこと

### 5-1. ケースの形: トレイ＋角のふた（設計書 §5 の「上枠」から変えた）

設計書 §5 は「上枠が角を覆い、基板とプレートを下から入れ、底板で閉じる」だった。作図して、
**上枠の前後の長い辺を基板に留める場所が無い**と分かった: 上枠は外周にしか無く、キャップの
下へは降りられない。外周で基板に届くには、キャップの縁の外に柱（インサート φ3.2 ＋肉）を
立てる幅が要り、前後に 5〜6mm 深くなる（外形 約 105〜108mm）。角にしか留められない上枠は、
継ぎ目の端（中央）が 115〜145mm 先で浮く。

トレイ（底＋外壁を 1 つの部品に）なら、トレイは**キーの下のナット**で基板に何か所でも留められ、
壁と床が一体なので浮く端が無い。D6（ふたの縁をキャップの隙間と外周に重ねる）・D13（印刷部品を
それぞれ基板に留める）はそのまま満たす。代償は、上から見えるキャップ↔壁の隙間からプレートの
縁が見えること（隙間 1.025）。**利用者に確認したいこと 1**。

### 5-2. 角

- **左**: XIAO を表に平らに（ピンヘッダは使わない。浮かせると 2.5mm 厚くなり、アンテナと地板の距離も変わる）。
  パッドは XIAO の外形から幅方向へ 0.6 出す（こて先用。前は基板の銅の限界、奥はプレートの開口の縁）。
  **XIAO はプレート・スイッチより先にはんだ付けする**（奥のパッドはプレートの下になる）。
  USB-C の口は外面から 0.3 内（HHKB と同じ）。壁は口の下までがトレイ、上はふたの舌（基板を上から
  落とすため）。ふたは奥の垂れ壁を持たない（XIAO 17.78 がセル 19.05 − 隙に入らない）。
  ふたは H3 のネジ 1 本で下から留める（基板の上のナット）
- **右**: ホルダの＋のパッドの外端を基板の縁から 0.675 内。ふたは天板 1.2＋キー側の垂れ壁 2 辺で、
  トレイから立つ柱（φ5.2・基板の穴 φ6.0 を通る・上端に M2 インサート）へ上から 1 本のネジで留める。
  柱はホルダの左、電池を起こす指の場所の外（ホルダから 3.0 以上）
- **電源スイッチ**: 裏の右端、ホルダのパッドから位置決めの穴を 0.6 離す y。トレイの右の壁に上に開いた
  切り欠き（ふたの舌が上を塞ぐ）と、外面に深さ 1.0 の指の窪み。つまみの先は外面と面一で、鞄の中で
  引っかからない

## 検討して捨てた案

| 案 | 捨てた理由 |
|---|---|
| 上枠＋底板（設計書 §5 の元の案） | 上枠の前後の辺を基板に留める場所が無い（§5-1） |
| XIAO をピンヘッダで浮かせる | +2.5mm 厚い。アンテナと地板の距離が変わる（rf-antenna.md） |
| 電源スイッチを表（角の中）に | JLC の実装が表に増える（D8）か手はんだの小さい SMD が増える |
| 電源スイッチのつまみを外へ 0.7 出す（本体の縁を基板の縁に合わせる） | つまみ側の耳のパッドが外形に 0.25 はみ出す（図を読み直して判明） |
| 取付を 1u のキーの間に | 桟 5.25 にナットの穴と肉が入らない。穴のコートヤード r2.45 がスイッチのコートヤードに重なる |
| 基板 1.2 | 全体は薄くならず、たわみが 2.4 倍（§2-4） |
| 壁 2.4 | XIAO の基板が壁に 0.57 食い込む（USB の口を 1.0 以内に保つと） |
| 電池ホルダ MY-1632-03（高さ 4.0） | − 極が基板のパッド。接触を基板の仕上げに預ける |

## この決定が乗っている前提（動いたら読み直す）

- スイッチの足が基板の上面から 3.0 出る（Choc V1 直付け）。**足を切りそろえるなら §2-5 の下の空きを読み直す**
- ケースに基板を**上から**落とす（だから USB と電源スイッチの壁の切り欠きが上に開き、ふたの舌で塞ぐ）
- ネジの相手は基板の上面のナット。**プレートの六角の穴はナットの回り止め**（プレートを外すとナットが回る）
- 左右の角のプレートの開口は外周まで開いている（`PLATE_OPENINGS`）
- XIAO のアンテナの位置は公式 STEP の向き（フットプリントの 3D 変換で解いた）。XIAO の版が変われば測り直す
- 1u のキーが並ぶ所に取付は置けない（1u の桟 5.25）。配列が変われば find_mounts を回し直す
