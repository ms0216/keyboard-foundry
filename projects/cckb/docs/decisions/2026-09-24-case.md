## 1. なぜ決める必要が生じたか

境界（外形・高さ・取付・角の部品の位置）は凍結したが、刷れる立体は無かった（open-gaps #3）。
印刷は利用者のお金と時間がかかるので、刷る前に組み立てモデルで干渉・経路・肉厚を確かめ、
嵌め合いの分からない所は先に小片で確かめる順にする。

## 2. 事実はどうか

- **Choc V1 のステムの穴**（Kailh CPG135001D01-16、<https://raw.githubusercontent.com/keyboardio/keyswitch_documentation/master/datasheets/Kailh/CPG135001D01-16.pdf> を 400dpi で読んだ）:
  上面図のステムに矩形の穴 2 つ。寸法線「2−3.00」「2−1.20」「5.70」。5.70 の寸法線の端は
  2 つの穴の中心を通る一点鎖線（上の穴の中心と下の穴の中心の間 = 図上 188px ≒ 5.7mm・15.00 の
  寸法線 492px で縮尺を取った）。図の縦方向は基板のボス φ1.9（±5.5）の方向で、フットプリント
  （kiswitch・KiCad の x ±5.5）ではキーの **X**。→ 穴は X に 5.70 離れて並び、各々 X 1.20 × Y 3.00
- 同じ図の側面: 基板の上面から下へ、足 3.00・突起 2.65。つば 15.00 角・厚さ 0.80
- 基板: `tools/kb cckb pcb` と同じ生成器でいま作った基板を KiCad の Python で読んだ（パッド 444・部品 134）。
  スイッチの足・突起の位置はこの穴から取った

## 4. 決めたこと

### 4-1. 左のふたは H3 のインサートで基板に締める（境界の決定から変えた）

境界の決定は「H3 の相手は基板の上面のナット、回り止めはふたのボスの六角の穴」だった。作図すると
**ナットはふたを留めない**: ネジはナットを基板へ引き付けるだけで、ふたのボスはナットのまわりに
被さっているだけなので、ふたは上へ抜ける。ナットの下にふたの床を挟むと、ネジの先 6.9（当時。床 1.2 の後は 6.5 で、ナット・インサートとの関係は同じ）に対して
床 0.4 でかかり 1.5（床は 0.2 層 × 2 の膜）、床 0.8 でかかり 1.1 と、どちらも苦しい。

→ **ふたのボスの下面を基板の上面に当て、ボスに M2 熱圧入インサート（外径 3.2・長さ 3.0）を入れ、
下からの M2×6 皿で締める**。ネジは 1.9 かかる。ボスの肉は奥 1.23・左 1.20（XIAO まで 0.9 空く）。
ナットの六角の穴だと肉は奥 0.6・左 0.9 にしかならなかった。ふたは基板に締めるので、左の角の壁は
ふたの下面から 0.2 下げる（二か所で当てない）。**基板側は変わらない**（H3 は穴 φ2.2 のまま。
ナットの占める円 r2.31 よりインサートのボスの下面 r2.7 がわずかに大きいが、H3 のまわりは
XIAO のパッドまで 2.9 空いている）。インサートの外周はアンテナのチップから 6.0（境界の要件 5 以上。ナットの外接円なら 5.3）。

### 4-2. 右のふた（電池のふた）

トレイの柱（φ5.2・上面は縁から 3.2 下）にインサート。ふたはボス（φ5.2・高さ 2.0）を柱に当てて
上から M2×6 皿で締め、頭は天板と面一。ネジは柱のインサートに 2.8 かかる。ボスの下端に**厚さ 0.4 の
膜（穴 φ1.6。M2 の谷径 1.57 とほぼ同じで、刷った穴は縮むのでネジ山が膜を切る）**を残し、最初にネジを膜にねじ込んでおくと、柱から外しても
ふたから落ちない（HHKB で「袋に入れる小物」を嫌った）。柱の肉はインサートの下穴 3.0 に対して 1.1
（境界の決定の「外径 3.2＋肉 1.0」）。電池の上 1.3・ホルダの上 0.3 空く。電池は半分（1.6）浮くと
ふたに当たる。

### 4-3. 壁の切り欠き（上から落とすので上に開く）

- USB-C: メスの外形＋片側 0.4（9.74 × 4.0）。上は左のふたの舌。プラグの樹脂の先はメスの口から
  1.0（見える金属）で、外面の 0.7 外に止まる
- 電源スイッチ: つまみの動く範囲＋片側 0.3。上は右のふたのひれ（厚さ 1.6・幅 3.2）。外面の指の窪み
  （深さ 1.0・幅 8・高さ 1.2〜3.6）。**窪みの奥の壁は 0.6**（壁 1.6 − 1.0）。構造ではない目隠しだが
  1.2 を割る（検査は理由つきで 0.6 を下限にしている）。窪みの上端をひれの下端 3.6 に揃えた
  （4.6 まで掘るとひれの根元に厚さ 0.6 の段ができた——断面を描いて見つけた）

### 4-4. キーキャップ

平らな天板にしたのは、境界の決定が「天板の下面 = ステムの上面・押し切ると天板の下面がハウジングの
上面」に積み上げを決めているから。スカート 1.0 は押し切っても下端 9.0 で、スカートの内側 15.6 は
つば 15.0 の外 0.3 を通り、プレートの上面 7.2 まで 1.8 空く。刷る向きは天板を下にして、脚と
スカートが上に立つ（サポート無し）。天板の感触はベッドの面で決まる。

### 4-5. 継ぎ目

案 C の折れ線から片側 0.1 ずつ引いた 2 つの領域でトレイを切る。38 本の柱・10 のボス・ふたの柱は
どれも片方に丸ごと入る（検査）。床は y = 0 で段になる（`section_seam_wall.png`）。

## 5. 検査（tests/test_cckb_case.py・38 本。壊す検査を含む）

| 検査 | 壊し方（落ちることを確認） |
|---|---|
| 全部品が 168.4 以内（17 個） | 継ぎ目を 40 にする → 左のトレイ 185 |
| 干渉 0（22 群・立体 295・B-rep） | 電池 +1mm、縁を下げてふたがホルダに当たる |
| 設計どおりの重なり（インサートの圧入・ネジが膜を通る）が理由の量だけ | 膜の穴を 2.4 にする（捕まえない） |
| 押し切ったキャップが何にも当たらない | キャップを壁の外まで広げる、スカートを 3.5 |
| 入れる経路（基板を上から・ふた・電池・プラグ・ネジとドライバー・キャップ） | メスを 1.5 奥へ、ホルダを奥へ、つまみの切り欠きを狭く、ドライバーを太く |
| 留まるか（電池・ふた・ネジのかかり） | 縁を上げる（電池が浮く）、ネジを 4mm に |
| 爪がかかるか | 窪みを無くす |
| 肉厚（名前つき 23 か所＋キャップ 3＋縦の走査） | 壁 0.8、ふた 0.8 |
| 継ぎ目が柱を切らない | 継ぎ目を柱の上へ |
| 滑り止めとネジの座ぐりの面の取り合い | くぼみを大きく |
| スタビのハウジングが床に届かない（O2） | ハウジングを 6.0 に |

丸めの削りかす（基板の座標を 1e-4 に丸めたために、プレートの開口とスイッチが 0.00005mm 重なる）は
6 件・計 0.005mm³ で、0 に数えて**件数を検査で縛る**（10 件を超えたら落ちる）。

## 6. この決定が乗っている前提（動いたら読み直す）

## 7. 検討して捨てた案

| 案 | 捨てた理由 |
|---|---|
| H3 をナットのまま（ふたのボスは回り止め） | ふたが上へ抜ける（4-1） |
| H3 のナットの下にふたの床を挟む | 床 0.4 でネジのかかり 1.5（床が膜）・床 0.8 でかかり 1.1 |
| 電池のふたを磁石で | 部品が増える・鞄の中の鉄に付く |
| キャップを段差のある形に | 境界の高さ（上面 14.2。床 1.2 の後は 13.8）を超えるか、押し切りの隙が減る |
| 窪みを 4.6 まで掘る | ひれに 0.6 の段 |
