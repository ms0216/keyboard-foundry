# 買う物の一覧（CCKB・1 台ぶん）

**結論: Amazon の 1 つのカート（箱は 3 つに分かれる）と、大阪・日本橋のシリコンハウスを回れば、ほとんど揃う。
Amazon にも日本橋にも無いのは Choc のスタビだけ（遊舎工房。スイッチも同じ箱で買う）。海外の注文は無い。
部品代 ¥12,962 ＋送料 ¥550 ＝ ¥13,512（PLA を買うなら ＋¥1,676）。送料は Amazon ¥0・日本橋 なし・遊舎工房 ¥550。**

**起動試験（#1）には何も買わない。**可変電源・HHKB の試作の XIAO と 100Ω・手持ちの CR1632 と 1MΩ で足りる
（2026-09-25 に試験を作り直した。[task-10a-coin-cell-startup.md](task-10a-coin-cell-startup.md) §3）。

**買う順番が大事**: 先に **日本橋（電源スイッチ）・遊舎工房（スタビ）** を済ませる。
起動試験（#1。部品を待たずにできる）と、届いたら電源スイッチの入の向きと高さ（P5・O13）・スタビのワイヤ（P11）を確かめてから、
**最後に JLCPCB に基板を頼む**（どれも「違ったら基板を直す」ものなので、発注前にしか直せない）。
手順は [order-steps.md](order-steps.md)。

**表の見方**: 値段と在庫は **2026-09-25 に各店の商品ページで見た値**（Amazon は商品ページの「在庫あり」「残り N 点」と
出荷元・販売元）。**「未確認」はページで確かめられなかったもの**（買うときに見る）。
在庫は日々動くので、買う直前にページを見る（日本橋の店頭の在庫は電話で聞く）。

## 4. 起動試験のダイオード: 足つきの BAT46・1N5819 で代えられるか → 代えられない（置き換えた・記録として残す）

> **2026-09-25 に置き換えた**: 起動試験はダイオードを使わなくなった（task-10a §2）。下の比べ方は「実物を 1 個測っても
> 典型値しか分からない」ことの記録として残す。D_PWR の品番（BAT46W）は保証値で決めた（open-gaps O12）。

足つき（ブレッドボードにそのまま挿せる）の BAT46（DO-35）と 1N5819（DO-41）で、基板の BAT46W・B5819W（JSCJ・SOD-123）の
代わりになるなら、LCSC の注文も変換基板も要らなくなる。起動試験が測るのは**順電圧（0.2〜10mA）と、低い逆電圧の漏れ電流**なので、
その範囲のデータシートの値を比べた。**どちらも代わりにならない**（当時は LCSC の SOD-123 を買うことにした。上の §3-2 で置き換えた）。

| 比べるもの | 基板の品（JSCJ） | 足つき | 同じか |
|---|---|---|---|
| **BAT46W ↔ BAT46**: 順電圧の保証値 | ≦0.25V @0.1mA・≦0.45V @10mA・≦1V @250mA | ST BAT46: 同じ 3 点で同じ値 | 同じ |
| 逆電流の保証値（1.5V・25℃） | ≦0.3µA | ≦0.5µA | 違う（足つきが緩い） |
| **順電圧の典型（25℃）** | 1mA 約 0.21V・**10mA 約 0.30V**（JSCJ の Forward Characteristics） | 1mA 約 0.26V・**10mA 約 0.40V**（ST Fig. 1-1） | **10mA で約 0.1V 違う** |
| 逆電流の典型（25℃・10V） | 約 0.4µA | 約 0.3µA（ST Fig. 2） | 近い |
| **B5819W ↔ 1N5819**: 保証値 | ≦0.6V @1A・≦1mA @40V だけ | Vishay 1N5819: ≦0.6V @1A・≦1mA @40V だけ | 同じ（ただし 1A の値で、試験の範囲は保証なし） |
| 順電圧の典型（25℃） | 曲線は 0.1A（約 0.3V）から上しか描いていない | 10mA 約 0.2V まで描いてある | **比べられない**（基板の品の低い電流の値が無い） |
| 接合容量の典型（4V・ダイの大きさの目安） | 約 60pF（JSCJ の曲線） | 約 100pF（Vishay Fig. 6。表の典型は 110pF） | **約 2 倍違う ＝ ダイが違う** |

- BAT46 はメーカーが違い（ST と JSCJ）、順電圧の典型が 10mA で約 0.1V 違う。起動の余裕はこの 0.1V で変わるので、足つきで測った
  結果を基板の品に当てはめられない
- 1N5819 はダイの大きさが約 2 倍違い（容量から）、基板の品は試験の電流の範囲の値がそもそも無い。低い電流の順電圧と漏れ電流は
  ダイの大きさで変わるので、足つきで測っても基板の品の値にはならない。**店で売っている 1N5819 のメーカーも分からない**
- 出典（2026-09-25 に取得・pdftotext と、描いた曲線を目で読んだ）: JSCJ BAT46W <https://datasheet.lcsc.com/datasheet/pdf/f97c8b3ccdb24c5ba21cb2c31ad9c922.pdf>・
  JSCJ B5819W <https://datasheet.lcsc.com/datasheet/pdf/4ac2c059be7c462694ab0715ce987a85.pdf>・
