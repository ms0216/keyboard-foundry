# 部品ごとの「効く条件」と、何で確かめたか（cckb）

**外** = データシート・API・実測で確かめた / **未** = まだ。「たぶん大丈夫」は未。
**自分の生成物（コード・コメント）どうしの一致は「外」ではない。**

選ぶ前に効く条件を全部並べてから候補を比べる。1 つの軸（Basic か・安いか）だけで
選ばない（HHKB でショットキーとシフトレジスタを選び直した）。foundry/parts.py に
HHKB で確かめた部品と理由がある——**理由の前提が自分の機種でも成り立つか**を読む。

## 結論（2026-09-24・基板の段）

JLC が裏に実装するのは 5 種 70 個（BAT46W 62・74LVC595 2・0.1µF 2・1MΩ 2・B5819W 1・電源スイッチ 1）。
**Extended は 3 種（74LVC595・BAT46W・MK-12C02）で段取り費 $9。**表の XIAO とホルダ、スイッチ 62 個は
利用者が手はんだ（BOM・CPL から外してある。`tools/kb cckb fab-fields` が焼き、
tests/test_cckb_pcb.py::test_jlc_parts_are_all_on_the_bottom が見る）。

## 1. 74LVC595（SN74LVC595APWR / C52287685）

| 効く条件 | 確かめたか | 値 |
|---|---|---|
| 動作電圧の下限（電池の打ち止めで動くか） | HHKB で外（foundry/parts.py: 1.1〜3.6V）。**この段では TI の表を読み直していない** | CR1632 → B5819W の後ろのレールは 3.2−0.4 = 2.8V から打ち止め（overlay の仮 2.4V → 約 2.0V）まで。下限が 1.1 でも 1.65 でも内側。74HC595（2.0V〜）は下限ぎりぎりで採らない |
| 動作点での保証値 | HHKB で外（1.8V で ±4mA） | 列は行のプルダウンへ 0.2mA 級を流すだけ |
| フットプリントと帯 | 外（KiCad 標準 TSSOP-16_4.4x5mm・板の上で） | コートヤード 7.7×5.5 が段 2|3 の帯の空き 7.05（行 2 のバスと段 3 の端子 1 の間）に入る。板で DRC 0 |
| ピン配置 | 外（SCASE93A Table 4-1）↔ pinmap.py | QA=15・QB..QH=1..7・QH'=9・SRCLR=10・SRCLK=11・RCLK=12・OE=13・SER=14。tests/test_cckb_pcb.py が overlay の &shifter n と板の Q を突き合わせる |
| 在庫・代替 | 外（API） | 上の表 |

選んだ理由: HHKB で実機確認済み（D5）。比べた: 74HC595（下限 2.0V）・Nexperia C426713（倍の単価・予備）。

## 5. 電池ホルダ BS-16-B4AK003（C964732）

ランド 3.75×4.5 外外 28.0 は図面 MY-CP-0085 と EasyEDA（BAT-SMD_BS-16-B4AK005、同じ形の兄弟品番）で一致。
**＋はパッド 1**（図面の＋の印の側・EasyEDA のシルクの＋）。板では＋が外側（x 140.6）で、裏の電源スイッチの
② へ最短。検査 `test_the_holder_pads_are_the_drawing_land`。

## 6. XIAO nRF52840（表・平ら・手はんだ）

公式 STEP（lib/xiao.3dshapes・無改変）を測った: 裏のパッド 14 個は幅 1.524・縁から内へ 2.03＋半円 0.762、
キャステレーション φ0.635 は縁の上、ピン中心は長手で基板の中心から USB 側へ −0.064（spec.XIAO_PIN_SHIFT）。
裏にはほかに露出パッドが 6 つ（縁から 3.39 より内）→ **XIAO の下は表の銅を禁止**（ルール領域 XIAO_UNDERSIDE）。
フットプリント lib/xiao.pretty/XIAO_nRF52840_SMD はパッドを縁から内 2.85・外 0.6。検査
`test_the_xiao_pads_cover_the_castellations_of_the_official_step`（STEP を毎回測る）。
**手前の列 D0〜D6 はパッドの外寄りに φ0.6/0.3 のパッド内ビア**（段階 1 の「穴なし」から変えた。
手前は基板の縁で、XIAO の下は表の銅が禁止なので、表では外へ出る道が無い）。はんだが少しビアへ吸われる。

## 7. 0.1µF（C49678）・1MΩ（C17514）

Basic・在庫十分。パスコンは各 595 の VCC（16 番）の隣（パッドの端どうし 0.95）。分圧 1MΩ+1MΩ は
スイッチの後ろ・ショットキーの手前（1.5µA）。

## まだ確かめていないもの
