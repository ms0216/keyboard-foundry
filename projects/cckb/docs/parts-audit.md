# 部品ごとの「効く条件」と、何で確かめたか（cckb）

**外** = データシート・API・実測で確かめた / **未** = まだ。「たぶん大丈夫」は未。
**自分の生成物（コード・コメント）どうしの一致は「外」ではない。**

選ぶ前に効く条件を全部並べてから候補を比べる。1 つの軸（Basic か・安いか）だけで
選ばない（HHKB でショットキーとシフトレジスタを選び直した）。foundry/parts.py に
HHKB で確かめた部品と理由がある——**理由の前提が自分の機種でも成り立つか**を読む。

## 結論（2026-09-24・基板の段）

JLC が裏に実装するのは 4 種 69 個（BAT46W 63〔キー 62・電源の D_PWR 1〕・74LVC595 2・0.1µF 2・1MΩ 2）。**D_PWR は 2026-09-24 の 2 回目の監査で既定を B5819W から BAT46W に替えた**（§3・open-gaps O12 で利用者が決める）。
**Extended は 2 種（74LVC595・BAT46W）で段取り費 $6。**表の XIAO とホルダ、スイッチ 62 個、
**表の電源スイッチ SS-12D00G3（秋月電子・スルーホール・2026-09-24 に置き換え・§4）**は利用者が手はんだ（BOM・CPL から外してある。
`tools/kb cckb fab-fields` が焼き、tests/test_cckb_pcb.py::test_jlc_parts_are_all_on_the_bottom が見る）。
CPL の座標と回転は、JLC の部品データ（EasyEDA の原点とパッド）で置き直して板のパッドと比べる

## 3. 電源のショットキー D_PWR: BAT46W（C54110・既定）／ B5819W（C8598）

> **2026-09-24 の 2 回目の監査 A2-1**: 下の表の「JLC の 8 品番を比べて…両方満たす品は無かった」は、分圧が吸う電流を
> 引かず、BAT46W の最大値と B5819W の典型値を比べた誤り。正しい物差し（電池に入る正味 ＝ 逆漏れ − Vbat/2.04MΩ、

> 電池へ入らない・Vf の保証値 ≦0.45V@10mA は B5819W の ≦0.6V@1A より低い）。最後に決めるのは発注前の利用者（open-gaps O12）。

## 6. XIAO nRF52840（表・平ら・手はんだ）
