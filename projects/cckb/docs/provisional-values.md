倍以上ずれていたことがある）。確定したら行を消し、コードのタグも外す（残ると落ちる）。

## 確定させる順番

1. 買う・刷る前に決まるもの（データシート・API で閉じるもの）
2. 部品が届いたら測るもの（ノギス。**定義と測定対象を一致させる**——「箱」と書いて
   測ったのが電極だった）
3. 組んでから測るもの

## 確定させたときの手順

1. spec.py の値を直し、`[暫定]` を外す
2. この表から行を消す（残ると検査が落ちる）
3. 根拠（測り方・日付・値）を docs/ のどこかに残す
4. `.venv/bin/pytest tests` と、形に関わるなら `tools/kb <機種> plate` / `pcb` を回す
