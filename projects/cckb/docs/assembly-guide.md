# 組み立て手順書（CCKB）

**結論: 刷る → 基板を確かめる → 表の XIAO・電池ホルダ・電源スイッチ（この順）をはんだ付け → スタビを基板にねじ留め → プレート（とスペースの枠） →
スイッチ 62 個を全部はめてから一度にはんだ付け → ファームを焼いてキーを全部試す → ケースに入れる、の順。
いちばん大事な決まりは「USB を挿す前に電源スイッチを OFF」と「ナットを入れたら裏返さない」。**

- 刷り方（スライサーの設定・小片の選び方・刷る順）の正本は [printing-and-assembly.md](printing-and-assembly.md) §1〜§4。ここでは繰り返さない
- 買う物は [shopping-list.md](shopping-list.md)、基板の頼み方は [order-steps.md](order-steps.md)
- 絵は `build/` にある（git に入れていない。無ければ `.venv/bin/python3 projects/cckb/case.py`〔STL・プレートの絵〕、
  `.venv/bin/python3 projects/cckb/assembly.py`〔断面図・分解図〕、`tools/kb cckb render`〔基板の絵〕、
  `.venv/bin/python3 projects/cckb/tools/draw_psw.py`〔`psw_section.png`・`psw_corner_iso.png`〕で出る）。
  全体の分解図は `build/cckb/assembly_exploded.png`、回して見られる模型は `build/cckb/assembly/cckb.blend`（Blender）

**道具**: はんだごて（細い先と、インサート用に太い先）・はんだ・フラックス・はんだ吸い取り線・テスター（導通と µA）・
ノギス・精密ドライバー（**軸の太さ 3.0 以下**。下の座ぐり φ4.2 に入る）・マスキングテープ・ニッパー。

## 手順 0. 刷る（基板を待つあいだに）

1. **小片を先に刷る**（5 個・約 1 時間 20 分。V2 の `coupon_stem` は十字の穴の格子と筒の外径・スタビの受け口）。実物（スイッチ・スタビ・ナット・インサート・M2 ネジ）をはめて値を選び、
   `case_spec.py`／`spec.py` を直して `case.py` で出し直す → [printing-and-assembly.md](printing-and-assembly.md) §1
   - **確かめ**: どの値を選んだかを台帳 [provisional-values-case.md](provisional-values-case.md) に書き、選んだ定数の `[暫定]` を外す
   - **インサートの外径**を測る。3.2 と違えば `INSERT_OD` も直す（3.8 を超える品は使わない。基板の銅に触れる・open-gaps P8）
2. **プレート → キーキャップ → ふた**を刷る（§2 の順）
3. **トレイは基板が届いて外形を測ってから**刷る（1 枚 約 3 時間半〔3h24m・3h08m〕。幅 286.35・奥行き 95.85 から +0.2 を超えたら
   `CASE_PCB_GAP` を上げて出し直す・open-gaps P12）

## 手順 1. 届いた基板を確かめる（はんだ付けの前）

1. **見る**: 裏に JLC が付けた部品が 69 個（ダイオード 63・IC 2・コンデンサ 2・抵抗 2）。ダイオードの帯の向きが
   全部そろっているか。**基板を左右に裏返して**（手前の縁は手前のまま）裏を見て: 縦 58 個は帯が手前、スタビのキーの
   横 4 個（Enter・左 Shift・スペースの左と右の下）は帯が右、D_PWR は帯が左（板のカソードの位置を KiCad で読んだ。
   上下に裏返すと縦の 58 個が奥に見える・4 回目の監査 E 軽微 1）
2. **導通を見る**（テスター。電池も XIAO もまだ無い状態で）:

   | 当てる所 | 期待 |
   |---|---|
   | GND どうし（電池ホルダの − のパッドと、XIAO の GND のパッド） | 鳴る |
   | 電池ホルダの ＋ のパッド と GND | **鳴らない** |
   | XIAO の 3V3 のパッド と GND | **鳴らない** |
   | 電源スイッチの真ん中の穴（パッド 2） と 電池ホルダの ＋ | 鳴る |

   「鳴らない」の所で一瞬鳴って止まるのは、コンデンサが充電される音で正常。鳴り続けたらショート。
   **通るまで先へ進まない**（[fab-checklist.md](fab-checklist.md) §5）。XIAO を付けた後（手順 2）にも 3V3 と GND をもう一度見る
3. **外形をノギスで**（手順 0 の 3）

## 手順 2. XIAO を表の左の角に平らに付ける（プレートより先）

**プレートより先**なのは、奥の列のパッドの外端がプレートの開口の縁とほぼ同じ位置（0.035 内）で、プレートを付けた後の手直しが狭いから（ケースに入れた後も、左のふたを外せばこては届く）。

絵: `build/pcb_view/cckb.pcb.cckb_main__U_MCU.png`（基板）・`build/cckb/section_left_corner_usb.png`（断面）

1. **手前の列 D0〜D6 のパッドには穴（パッド内ビア φ0.8/0.3）がある**。先にビアの上にはんだを少し流して穴を埋め、
   **はんだ吸い取り線で平らにする**（山のまま載せると手前の縁だけ浮く）
2. **奥の列（D7〜5V）のランドの内側の端には、はんだを先に盛らない**。D7 のランドの奥の端から 0.43 先に XIAO の裏の
   NFC2 のパッドがあり、触れると CS が NFC の端子に繋がる（open-gaps A9）
3. XIAO を載せる。**USB 側の端を基板の縁より外に出さない**（壁の内面まで 0.53）。キャステレーション（縁の半円の穴）の
   側からこてを当てて、四隅 → 残りの順に付ける
4. **フラックスを IPA（イソプロピルアルコール）で拭く**。特に D0 のまわり: D0 は電池の電圧を測る分圧（1MΩ＋1MΩ）の
   真ん中に繋がっていて、残ったフラックスの漏れが読みを狂わせうる（4 回目の監査 D 軽微 3）
5. **確かめ**: 横から見て浮いていない。隣どうしのパッドがはんだで繋がっていない（ルーペ）。XIAO の裏の露出パッド 8 個と
   USB のシールドの長穴 4 個の下には表の銅が無い（設計で確かめた）ので、はんだが回り込まなければショートしない

## 手順 3. 電池ホルダを表の右の角に付ける（電源スイッチより先）

絵: `build/pcb_view/cckb.pcb.cckb_main__BT1.png`・`build/cckb/section_right_corner_cell.png`

**電源スイッチより先**なのは、ホルダの ＋ のパッドの右端と電源スイッチの本体の間が 0.5 しかなく、スイッチを付けた後は
＋ のパッドの外側にこてを当てにくいから（2026-09-24 に電源スイッチをホルダの右へ置いた）。

1. **＋ の向き**: ホルダの ＋ のクリップが**外側（右・電源スイッチの側）**。基板のシルクの ＋ に合わせる（シルクはホルダの縁に
   半分隠れる・open-gaps A5。載せる前にシルクを見ておく）
2. 端子 2 つをはんだ付け（パッドが大きいので、こてを長めに当てる）。＋ のはんだは右の電源スイッチの 3 つの穴に流さない
3. **確かめ**: 電池はまだ入れない

## 手順 4. 電源スイッチ SS-12D00G3 を表の右の縁に差して、裏からはんだ付け → 足を切る

絵: `build/cckb/psw_section.png`（断面: スイッチ・基板・ふたの穴と高さ）・`build/cckb/psw_corner_iso.png`（右の角を斜めから）・
`build/pcb_view/cckb.pcb.cckb_main__SW_PWR.png`（基板）

1. **付ける前にテスターで入の向きを確かめる**: レバーを片側へ寄せ、真ん中の足と**レバーを寄せた側の端の足**が導通する
   こと（図面の側面図と回路図の読み。基板は「レバーを奥へ押すと入」で、ふたに ON ↑ を刻んである）。逆に繋がる
   （レバーと反対側の足が導通する）なら、**付けずに Claude に言う**（ふたの刻印の向き spec.PSW_ON を反対にして刷り直す）
2. 表から 3 本の足を穴（φ0.8）に差す（向きはどちらでもよい——足は対称で、「レバーの側の足が繋がる」のは向きによらない）。
   本体を指で基板に押し付け、**本体の下の爪 4 つが基板に当たるまで**差し込む（本体はその分 0.4 浮くのが正しい）
3. 裏返して 3 本をはんだ付け（仕様書 JBL-SS/SK-2010 の手はんだ: 320±5℃・2±1 秒。長く当てない）。1 本付けたら表から見て
   傾いていないか確かめ、傾いていたらその 1 本を温め直して押す
4. **足を切る**: ニッパーで、はんだの山の上から**基板の下面から 1.0 以下**に切る（足は切らないと基板の下に約 1.9〜2.3 出て、
   床まで 1.8 しかないので床に当たる・`spec.PSW_PIN_TRIM`）。**キーのスイッチの足（手順 6）は切らない**のと違うので注意
5. **確かめ（電池を入れる前に）**: 電池ホルダの ＋ と D_PWR の帯の無い側（アノード）の導通 → レバーが奥（入）で鳴る・
   手前（切）で鳴らない。表から見て、レバーの先が基板の上面から 6.9 前後（名目。ふたの上面より 0.1 下になる高さ）。
   **ノギスで基板の厚さと、基板の上面からレバーの先までを測り、7.0 − (測った基板の厚さ − 1.6) 未満ならふたの上面から
   出ない**（ケースに入れた後は右のふたが基板を覆うので、ここで測る。公差の最悪では 0.36 出うる・open-gaps O13）。
   **切のとき、電源スイッチの奥の足（パッド 1）と真ん中の足（パッド 2）も鳴らないこと**を確かめる（open-gaps A11。
   枠の爪が両方のパッドに触れると OFF が効かなくなる。触れていたら爪の下にレジストか薄いテープを挟む）

## 手順 5. スタビを基板にねじで留め、プレートを載せる（Choc V2・`cckb-v2` の枝）

絵: `build/cckb/v2_plate_bites_after.png`・`section_stab_pivot.png`・`section_stab_across.png`・`section_stab_space.png`

スタビは遊舎工房の「Choc v2用スタビライザー 2U（スクリュータイプ）」A050001-01-1 ×4（Enter・左 Shift・スペースの左と右）。
**プレートには掛からない**。基板（1.6）に裏からねじで留める（販売者の図の断面 A-A: 箱の中にナット）。

1. **スタビ 4 組を先に基板に留める**（プレート・スイッチより先。後からはねじが回せない）。基板の**表**から:
   - 箱（5.80 × 7.30）を大きな四角い穴に、爪（φ3.5）を奥の丸い穴に差す。**ワイヤは奥側**（4 組とも。スペースも）
   - 爪が基板の裏でパチンと開くまで押す（爪の隙は 1.65。基板は 1.6 だが JLC の公差で最大 1.76 → きつければ無理に押さない・§10-5 の V3）
   - 裏返して、手前の小さい穴から付属のねじを締める（頭は基板の下面から 1.15 出る。床まで 1.8）
2. **確かめ**: 軸（十字）を指で押して、左右が一緒に沈み、戻る。ワイヤが基板に擦れない
3. プレート（左右 2 枚）を基板の上に置く。スタビの本体は U 字の羽の穴を通る（プレートの上に 2.8 出る）。まだ留まらない。継ぎ目は段ごとにキーの境目
4. **スペースの 2 キーだけ、プレートと別に刷った「枠」（`plate_frames_main.stl` の 2 つ・U 字）を使う**。羽がプレートの手前の縁まで抜けていて、
   スイッチの周りの板がプレートから切り離されているため（決定記録 2026-09-25-choc-v2 §10-6）。枠は手順 6 でスイッチにはめる
5. **確かめ**: スタビの本体・ワイヤがプレートの羽の穴の縁に触れていない（羽の奥の縁とスタビの爪の間は図で 0.47・見本で確かめる V9）

## 手順 6. スイッチ 62 個を全部はめてから、一度にはんだ付け

1. **62 個を全部プレートにはめ、基板の穴に通す**。**スペースの 2 個は、先に枠（手順 5 の 4）をスイッチの胴にはめてから**、枠ごと基板へ
   （枠の両脇の桟にスイッチの爪が掛かる。枠の開いた側〔U の口〕が奥＝ワイヤの側）。全部はめ終わってから裏返す
   （**1 個ずつ付けると、プレートの位置がずれて後のスイッチが入らない**）
2. 裏返したら、基板はスイッチのステムとスタビの軸の上（基板から 8.6）に載る（XIAO 4.47・ホルダ 5.5 はそれより低いので当たらない）
3. 足をはんだ付けする。**足の先にはんだの玉を作らない**（フィレットは足に沿わせる）: 足は基板の下に最大 1.76 出る。
   トレイの床の内側には、足・中心の突起・スタビの箱の真下に**深さ 0.4 の止まり穴**（256 個）があり、最悪の足でも穴の底まで 0.44 残る。
   玉があると穴の縁に乗って基板が浮き、がたつく。**足は切らなくてよい**（`spec.UNDER_PCB`・`FLOOR_POCKET_DEPTH`）。
   **切りそろえない**（2026-09-24 利用者の決定・open-gaps O10。厚さは床を 1.2 にして縮めた。切ると下の空きの前提が変わる）
4. **確かめ**: 表から見て、どのスイッチもプレートに浮かずに座っている。裏の足の先がとがっていない

## 手順 7. ファームを焼いて、キーを全部試す（ケースに入れる前に）

**USB を挿す前に電源スイッチを OFF。**（理由は下の「使い方」）

1. ファーム `cckb-xiao_ble__zmk-zmk.uf2` を GitHub の Actions（Build ZMK firmware の最新の成功した実行 → Artifacts の
   `firmware`）から取る。**どのコミットの物かを控える**
2. 電源 OFF のまま USB-C を挿し、XIAO のリセットボタンを**2 回すばやく**押す → ドライブが見えたら .uf2 をコピー
   （書き込みの「成功」を信用しない。ドライブの `CURRENT.UF2` の大きさを見る・[docs/knowledge/zmk-and-xiao.md](../../../docs/knowledge/zmk-and-xiao.md)）
3. USB のまま、メモ帳などで**62 キーを 1 つずつ**押し、全部が 1 回ずつ出るか見る。キー配置は HHKB の既定
   （`config/boards/shields/cckb/cckb.keymap`）。スペース 3 つは全部スペース
4. **同時押し**: 行列の四角の 3 つの角のキー（例 W・E・S）を同時に押して、4 つ目の角（D）が出ないか（ゴースト。キーごとのダイオードで防いでいる）。
   組は行列から選んだ: W＝行 1・列 3、E＝行 1・列 4、S＝行 2・列 3、D＝行 2・列 4（`cckb-transform.dtsi` の RC）。
   **見た目で四角でも行列で四角とは限らない**（例えば A・S・W の 4 つ目の角は行 1・列 2 で、そこにキーが無い。
   ダイオードが逆でも何も出ないので試験にならない・4 回目の文書の監査 重要 1）。`tests/test_cckb.py` が組を行列と突き合わせる
5. USB を抜き、**電池（CR1632・＋が上）を入れて電源 ON**。パソコン／スマホの Bluetooth に `CCKB` が出てつながるか。
   数キー打つ
6. **確かめ**: 出ないキーがあれば、そのキーのはんだ（手順 6）と、同じ行／列の他のキーが効くかで原因を分ける。
   列 1 本がまとめて効かなければ 595（JLC が付けた IC）の周り、行 1 本なら XIAO のはんだ（手順 2）を疑う

## 手順 8. ケースに入れる

絵: `build/cckb/section_mount_h0.png`（ネジ・ナット・ボス）・`section_left_corner_h3.png`（左のふた）・
`section_right_corner_cell.png`（右のふた）・`section_seam_*.png`（継ぎ目）

1. 電池を外し、電源 OFF
2. **インサートを熱圧入**: `tray_R` のふたの柱の上から 1 個、`lid_L` のボスの下面から 1 個（こてで押し込み、面一で止める）。
   `lid_L` のインサートの下の基板には表の銅が無い（H3 の禁止域）
3. **右のふたのネジを先に通す**: `lid_R` の天板の側から M2×6 をねじ込み、ボスの下の膜を抜けるまで回す。以後このネジは
   ふたから落ちない
4. **ナット 9 個**をプレートの六角の穴から基板の上に落とし、**9 か所の穴の上にマスキングテープを貼る**（キーの下の取付
   9 か所。左の角の H3 はナットではなくふたのインサート）。テープは**要る**: 下からネジをかけ始めるとナット（約 0.15g）が
   押し上げられて浮き、ネジ山が掛からない。テープがあればナットは 0.6 上がった所で止まり、まだ 1.0 が六角の穴の中に
   残る（回り止めが効く）ので、ねじ込める（4 回目の監査 E 軽微 3）。キャップの下に隠れるので貼ったままでよい。
   **ここから先は裏返さない**——ナットは六角の穴を通り抜けて落ちる
5. **トレイ**（左右）を机に並べ、基板の塊を**上から**まっすぐ落とす。XIAO の USB-C が、壁の上に開いた切り欠きに入る
6. **左のふた**を載せる（舌が USB-C の口の上を塞ぐ）
7. 机の端から少し出して持ち上げ（裏返さない）、**下から M2×6 皿 10 本**を締める（9 本はナットへ、H3 は左のふたの
   インサートへ）。**締めすぎない**（PLA の座が潰れる）
8. **電池**（CR1632・＋が上）をホルダの ＋ のクリップの下へ斜めに入れ、反対側を押し下げる
9. **右のふた**を真上から載せる。電源スイッチのレバーが、ふたの右端の四角い穴（6.4 × 2.4）に下から入る（レバーはどちらの端でも
   穴の中）。上からネジ（3 で通した物）を柱のインサートへ締める
10. **キーキャップ**を挿す。十字の筒をスイッチの十字に真上から（静音の V2 の窪み φ5.7 に入る）。2.25u はスタビの軸にも天板の下の十字の穴が入る。
    **斜めにこじらない**（筒の腕の先の肉は 0.675。抜くときは真上へ・§10-5 の V11）
11. 底の 4 つのくぼみ（**12×6**。奥の 2 つは角から少し内側・最上段と 2 段目の間）に**滑り止め**を貼る
12. **確かめ**: ふたの穴に上から爪を差し込んで、電源スイッチのレバーを両端まで擦れずに動かせるか。レバーの先がふたの上面から
    出ていないか（**ふたの上面に定規を渡すか、ノギスのデプスを当てる**。基板の上面からの高さは手順 4 の 5 で測った・
    公差の最悪では 0.36 出うる・open-gaps O13）（open-gaps P4）。USB-C のケーブルが奥まで挿さるか（P2）。
    机の上でがたつかないか。重さと厚さを量って記録する（設計書 §10b）

**電池を替えるとき**: 電源スイッチを OFF → 右のふたのネジを緩める（ネジはふたに残る）→ ふたを真上に外す（レバーは穴の中を
縦に抜ける）→ 電池をクリップと反対の縁から起こして出す。

## 使い方（説明書に書くこと）

- **USB を挿す前に電源スイッチを OFF にする。**USB を挿したまま ON にすると、USB の 3.3V からショットキー（D_PWR）の
  逆向きの漏れ電流が電池の側へ流れる。D_PWR の BAT46W（C54110）なら 25℃ ではデータシートの保証値でも分圧が吸う方が多く
  電池には入らないが、40℃ を超えると保証が無い
  （Energizer の上限 1µA。決定記録 2026-09-24-audit-fixes §S2・open-gaps 受け入れた差 A1）。**OFF なら電池は回路から
  完全に切り離される**。ファームの書き込み・USB での打鍵も OFF のまま行う
- OFF で USB を挿しているあいだは、電池の残量が実際と違って表示されることがある（ショットキーの漏れが電池の電圧を測る
  分圧に入るため。害は無い・open-gaps A2）
- 電源スイッチは右のふたの穴のレバーを爪で**奥へ押すと入**（ふたの「ON ↑」の向き。部品が届いたら手順 4 の 1 で確かめる）
- **OFF にしたら数秒待ってから ON にする。**すぐに入れ直すと、XIAO の中のコンデンサに電気が残っていてリセットされず、
  「入れ直したのに点かない」に見える（HHKB 分割機で起きた・HHKB open-gaps #44。待つ時間は基板が届いたら測る）。
  電池が尽きて自分から止まったとき（打ち止め）と、スリープから戻らないときは、どちらも電源の入れ直しで戻す
- パソコンに出る電池の % は目安にならない。CR1632 は使っている間の大半を平らな電圧で過ごし、終わり近くで急に落ちるので、
  ほぼずっと 6〜7 割に見える見込み（放電曲線の図の読み・測っていない。4 回目の監査 F 軽微 3）。電池が尽きる前触れは
  ほかに無く（状態の LED は使っていない・open-gaps F8）、尽きると黙って止まる
- 鞄に入れるときは OFF（キーが押されて起きるのを止める）
- USB を挿しているあいだは、キーで Bluetooth に戻せない（USB を抜く。open-gaps F1）
